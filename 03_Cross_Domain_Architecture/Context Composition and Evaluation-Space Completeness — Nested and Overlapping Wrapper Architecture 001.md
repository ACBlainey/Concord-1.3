# Context Composition and Evaluation-Space Completeness — Nested and Overlapping Wrapper Architecture 001

**Project:** The Concord Framework  
**Date:** 4 October 2026  
**Status:** CROSS-DOMAIN ARCHITECTURE / PROVISIONAL / NON-CANONICAL  
**Primary interfaces:** Contextual Wrapper Architecture (CWA); Evaluation-Space Completeness Problem (ESCP); ESCP Bounded Completeness Challenge; Decision Authorship and Contextual Participation; Authored Risk Acceptance; Bounded Transition Architecture (BTA); Cross-Boundary Externality Recognition

## 1. Purpose

A participant, object, event or decision can occupy several legitimate contexts at the same time.

The problem is not only:

> **Which rule or authority prevails when represented contexts conflict?**

A logically prior problem is:

> **Have the materially relevant contexts, relationships, state dimensions and externalities been represented at all?**

CWA already establishes that nested and overlapping wrappers do not automatically inherit, merge or acquire universal precedence. Its Precedence Resolution Router (PRR) decomposes conflicts and routes them without manufacturing sovereignty.

ESCP adds a prior safeguard:

> **Correct Resolution Within The Represented Wrapper Set != Completeness Of The Relevant Wrapper Set**

A resolver may correctly apply every known rule and still produce a globally invalid result if a materially relevant wrapper, relationship, participant, state, transition, protected boundary or externality is absent from the evaluation space.

This architecture therefore joins **context composition** to **evaluation-space completeness** without making either architecture universal or sovereign.

## 2. Core topology

The candidate operating chain is:

**Decision / Event / Proposed Action**  
-> **Declared Decision Object And Scope**  
-> **Candidate Context Set**  
-> **ESCP Context-Completeness Challenge**  
-> **Materially Relevant Context Set At Time T**  
-> **Decision-Object Decomposition**  
-> **Per-Context State / Authorship / Permission / Authority Mapping**  
-> **Conflict / Externality Detection**  
-> **CWA Precedence Resolution Router Where Needed**  
-> **Bounded Decision / Action**  
-> **State Monitoring**  
-> **BTA Transition On Material Change**  
-> **Selective Revalidation / Recomposition**  
-> **Termination / Withdrawal / Reversion / Review**

The ESCP stage does not prove reality complete. It asks whether the represented context set is sufficient for the declared decision and consequence at the relevant time.

## 3. Context set

Let the contexts represented by evaluator A be:

`W_A = {W1, W2, ... Wn}`

Let the contexts materially relevant to decision object Q be:

`W_R(Q,t)`

It is possible that:

`W_A subset W_R(Q,t)`

while every rule evaluation within `W_A` is correct.

Therefore:

> **Correct Wrapper Evaluation != Complete Context Evaluation**

and:

> **No Conflict Found In Represented Contexts != No Material Context Conflict Exists**

This is the wrapper analogue of ESCP's distinction between accuracy within an evaluation space and completeness of that space.

## 4. Context-completeness challenge

Before a consequential composition or precedence decision, ask:

> **What materially relevant context, relation, participant, state, authority source, protected boundary, externality, transition or failure mode would have to exist, be missing or be unrepresented for this contextual conclusion to be wrong or over-scoped?**

Candidate discovery routes include:
- participant/role mapping;
- relationship mapping;
- physical and logical boundary mapping;
- contract and obligation mapping;
- authority-source mapping;
- rights/protected-boundary review;
- externality review;
- temporal/state review;
- dependency review;
- heterogeneous observer review;
- failure-mode and adversarial challenge.

Discovery remains bounded by legitimate access, privacy, law, permission and authority.

> **Need To Discover Relevant Context != Authority To Inspect Everything**

## 5. Context relevance is decision-object specific

A context can be simultaneously active but irrelevant to a particular decision object.

Example: during a professional boxing match, the participant may simultaneously occupy:
- civil/legal context;
- sporting context;
- match context;
- employment/contractual context;
- medical-monitoring context;
- venue context;
- commercial/broadcast context.

A question about whether a punch scores may principally engage sporting/match rules.

A question about whether acute neurological signs require a medical stop engages a different decision object and authority topology.

A question about payment after the event engages contractual/commercial contexts.

Therefore:

> **Simultaneously Active Context != Materially Relevant Context For Every Decision**

and:

> **Same Event != Same Decision Object**

This prevents context accumulation from becoming universal cross-application.

## 6. Nested, overlapping and relational contexts

Three relations should remain distinguishable.

### 6.1 Nested

One context is physically or logically contained within another.

CWA already establishes:

> **Nested Context != Inherited Rule Set**

> **Parent Access != Child Access**

> **Parent Rules != Child Rules**

### 6.2 Overlapping

Two or more contexts apply simultaneously without one containing the other.

> **Overlapping Contexts != Merged Authority**

### 6.3 Relational

One context materially affects another without either being nested or coextensive.

Examples include an employment relationship affecting entry into a hazardous site, or a broadcast contract affecting commercial obligations around a sporting event.

> **Contextual Relationship != Rule Inheritance**

Relational context is important to ESCP because a materially relevant relationship may be omitted even when every visible physical wrapper has been mapped.

## 7. Composition is not merger

A composite state is a representation of simultaneous applicability.

It does not create a new sovereign authority by aggregation.

> **Context Composition != Authority Fusion**

> **Multiple Bounded Authorities != One Larger Authority**

> **Combined Permissions != General Permission**

Each permission and authority retains its source, function, scope, predicates, duration, accountability and termination conditions unless a legitimate architecture explicitly creates something different.

## 8. Decision-object decomposition

Before asking which context prevails, decompose the apparent conflict into the smallest materially useful decision objects.

For each object Q, record where relevant:

`Q = <Function, AffectedParticipants, RelevantContexts, MaterialStates, ProtectedConstraints, AuthorshipState, PermissionState, AuthorityState, Externalities, TimeHorizon, Reversibility, Unknowns>`

One event may produce several Q objects with different legitimate resolvers.

> **Apparent Context Conflict May Be Multiple Independent Decisions**

This extends the existing CWA PRR rather than replacing it.

## 9. Standing, authorship and authority remain orthogonal

For each decision object:

> **Standing != Authorship != Authority**

A participant may retain standing across all contexts while having decision-specific authorship altered in one context.

Established authorship of risky sporting participation does not create medical authority in the participant, referee, promoter or employer.

Medical expertise does not create authority over unrelated contractual or civil decisions.

> **Authorship In Wrapper A != Authority In Wrapper B**

> **Authority In Wrapper A != Authority In Wrapper B**

> **Loss Of Authorship For Decision A != Loss Of Standing Or Authorship For Decision B**

## 10. Selective state transition

A material event should not automatically mutate every active wrapper.

Let participant P occupy contexts:

`{W_sport, W_employment, W_medical, W_venue, W_commercial, W_civil}`

Suppose a neurological injury changes P's ability to author continuation of the bout.

The first transition may be:

`AuthorshipState(W_match, continuation) : A0 -> A3/A4`

and may activate a medical/protective state.

It does not automatically imply:

`EmploymentStatus = terminated`

or:

`CommercialRights = void`

or:

`CivilStanding = lost`

or:

`GeneralDecisionCapacity = absent`

Therefore:

> **Material State Change In One Context != Global State Change**

and:

> **Transition Propagation Must Be Justified, Not Assumed**

BTA should propagate only those dependent changes for which a legitimate dependency exists.

## 11. Authorship of entry and continuing composition

Decision Authorship architecture establishes:

> **Authorship Of State A != Automatic Authorship Of Materially Different State B**

and:

> **Authorship Of Entry != Irrevocable Authorship Of Continuation**

In multi-wrapper situations this becomes:

> **Authorship Of Entry Into Wrapper A != Authorship Of Entry Into Wrapper B**

> **Authorship Of Composite State A+B != Authorship Of Materially Different Composite State A+B+C**

A newly activated emergency, medical, security or other context may change the composite state enough to require new evaluation without erasing prior standing.

## 12. Externalities and non-participants

A wrapper cannot define away consequences that cross its boundary.

A boxing participant may author inherent sporting risk to self. That does not author equivalent risk to a spectator, employee, uninvolved third party or external system.

Cross-Boundary Externality Recognition therefore supplies an outward-facing check:

> **Internal Context Permission != External Permission**

> **Authored Self-Risk != Authored Third-Party Risk**

A context-completeness challenge should ask whether materially affected parties or systems exist outside the initially represented wrapper set.

## 13. Precedence comes after completeness challenge

CWA already correctly refuses to manufacture a universal precedence hierarchy.

This architecture adds the ordering rule:

> **Do Not Resolve Precedence Before Testing Whether The Material Context Set Is Adequately Represented**

The sequence is:

**Candidate Context Discovery**  
-> **Bounded Completeness Challenge**  
-> **Decision-Object Decomposition**  
-> **Conflict Detection**  
-> **Existing Legitimate Priority / Resolver Search**  
-> **CWA PRR**  
-> **Resolve / Route / Preserve UNKNOWN or DISPUTED**

A completeness challenge may itself terminate with residual uncertainty. It does not require impossible proof of exhaustive reality.

## 14. Consequence scaling

The ESCP companion establishes that completeness review depth should scale with consequence and irreversibility.

Applied to wrapper composition:

- routine, reversible, low-consequence local decisions may use a shallow context scan;
- high-consequence, rights-affecting or difficult-to-reverse decisions require stronger justification that materially relevant contexts and affected parties have been represented;
- time-critical emergencies may proceed under legitimate bounded authority while preserving incompleteness, provenance and later review.

> **Context-Completeness Burden Scales With Consequence And Irreversibility**

> **Incomplete Context Search != Automatic Requirement For Inaction**

> **Incomplete Context Search != Permission To Pretend Completeness**

## 15. Anti-paralysis

ESCP must not become an infinite-context veto.

A context-completeness review may terminate for the declared decision where:
- the decision object and scope are explicit;
- known material contexts and relationships are represented;
- plausible material omission pathways have been proportionately tested;
- unresolved material unknowns are explicit;
- further discovery has low expected decision relevance;
- reversibility, monitoring and review are proportionate;
- discovery methods were legitimate.

The result is:

`CONTEXT_SET_SUFFICIENT_FOR_DECLARED_DECISION_AT_TIME_T`

not:

`ALL_CONTEXTS_KNOWN`

## 16. Reopening and recomposition

A prior composition is not permanently closed.

Recomposition may be triggered by:
- new participant or affected party;
- new relationship;
- new wrapper;
- material state change;
- new externality;
- new authority claim;
- new evidence;
- changed risk;
- changed authorship;
- changed dependency;
- changed time horizon;
- anomaly indicating an omitted context.

> **Prior Context Composition != Permanent Context Closure**

Reopening should be routed through state-triggered review/BTA where appropriate.

## 17. Transfer tests

### 17.1 Professional boxing — PASS

Simultaneous sporting, match, employment, medical, venue, commercial and civil contexts are representable without merging authority.

A referee may possess bounded sporting stop authority. A clinician may possess bounded medical functions. An employer/promoter may possess contractual responsibilities. None thereby acquires universal authority over the participant.

A neurological state change can terminate or suspend match participation while leaving other standing and relationships intact pending their own transition rules.

**Result:** strong demonstration of selective transition and non-merger.

### 17.2 Hospital patient who is also employee/research participant — PASS WITH STRICT SEPARATION

One person may simultaneously be patient, employee and research participant.

Clinical consent does not become employment consent. Employment authority does not become research consent. Research withdrawal does not erase patient standing.

A medical emergency can alter treatment authority without silently authorising unrelated research use.

**Result:** strong transfer; context completeness is critical because omission of one role can produce serious authority error.

### 17.3 Custody — PASS WITH HIGH COMPLETENESS BURDEN

A detained participant may simultaneously occupy custody, medical, legal representation, family/communication, employment/property and civil-rights contexts.

Custodial authority is bounded to its legitimate function.

> **Physical Control != Total Contextual Authority**

Omitting a medical, legal or rights context could make an internally correct custodial decision globally illegitimate.

**Result:** strong ESCP relevance.

### 17.4 Research workplace — PASS

A worker may also be a research participant, laboratory operator, data subject and safety-role holder.

Employer authority does not automatically satisfy research consent; research permission does not erase workplace safety obligations.

**Result:** strong transfer.

### 17.5 AI/digital operation — PASS

An AI participant may simultaneously occupy sandbox, service, economic, communications, data-access and experimental contexts.

Permission in a sandbox does not become production permission. Experimental authority does not become authority over persistent assets or unrelated communications.

Promotion/deployment is a BTA transition requiring recomposition.

**Result:** strong transfer and substrate neutrality.

### 17.6 Emergency rescue — PASS WITH TIME-BOUNDED INCOMPLETENESS

An incident may combine public-space, property, medical, rescue-role, employment, infrastructure and emergency contexts.

Time may prevent exhaustive discovery. Legitimate emergency functions may act within bounded authority while recording unknowns and preserving review.

**Result:** demonstrates anti-paralysis without false completeness.

## 18. Failure modes

### 18.1 Wrapper blindness

A materially relevant context is absent from the represented set.

### 18.2 Authority bleed

Authority from one wrapper is silently applied to another.

### 18.3 Consent bleed

Consent/authorship in one wrapper is treated as consent in another.

### 18.4 State bleed

A state change in one wrapper is treated as a global participant state change.

### 18.5 Precedence-before-discovery

A resolver selects between represented contexts before testing whether another materially relevant context is missing.

### 18.6 Composite sovereignty

Several bounded authorities are aggregated into an imagined general authority.

### 18.7 Physical-context bias

Only spatial wrappers are represented while contractual, relational, informational, temporal or abstract contexts are omitted.

### 18.8 Internality error

A wrapper's internal rules are treated as sufficient even though material consequences cross its boundary.

## 20. Architectural result

Nested and overlapping wrappers should not be treated as a hierarchy problem alone.

The stronger model is:

> **Context Discovery -> Completeness Challenge -> Decision Decomposition -> Bounded Composition -> Conflict/Externality Detection -> Legitimate Resolution -> Selective Transition -> Recomposition**

CWA answers how represented contexts remain bounded and how known conflicts are routed.

ESCP asks whether the evaluation space supporting that routing is sufficient for the declared decision.

Decision Authorship determines whether the participant sufficiently authors the relevant choice.

Bounded authority determines what another actor may do.

BTA governs material transition.

Cross-Boundary Externality Recognition prevents the internal wrapper from erasing affected external parties.

Together they support a general rule:

> **No Context May Silently Absorb The Standing, Authorship, Permission, Authority, State Or Externalities Of Another Context Merely Because They Coincide In One Event.**
