## Authority interpretation

KCS's expressly assigned knowledge-state, provenance, dependency and propagation functions constitute its bounded standing functional mandate. KCS may perform ordinary work within that mandate without a new triadic vote for each action. It does not thereby acquire authority to adjudicate rights, govern participants, issue judicial orders, override domain custody, or turn recorded authority into live authority. The actor claiming an additional power must establish its valid mandate. See [the Domains-wide authority interpretation](../../../02_Domains/README.md).
