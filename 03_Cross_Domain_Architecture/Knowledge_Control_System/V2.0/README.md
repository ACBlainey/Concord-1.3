## Migration and integration rule

The five section files initially reproduce the complete original main KCS text in its original order (including the preamble in Section 01), with only section headings and migration notes added. The original main specification, all three companion upgrades, the material dependency index extension, the consequential classification contestability correction, and the operational dependency datasets remain intact as provenance and validation sources.

Integrate the living results of the companions **into the relevant operational sections**, not as a sixth appendix or concatenated companion dump. Preserve established KCS functions and semantics; consolidate overlaps without losing mechanisms, distinctions, test evidence or provenance. Create additional chapters or adjust section boundaries where the companion architecture genuinely requires it. The final five-section arrangement is not a fixed limit.

## Authority interpretation

KCS's expressly assigned knowledge-state, provenance, dependency and propagation functions constitute its bounded standing functional mandate. KCS may perform ordinary work within that mandate without a new triadic vote for each action. It does not thereby acquire authority to adjudicate rights, govern participants, issue judicial orders, override domain custody, or turn recorded authority into live authority. The actor claiming an additional power must establish its valid mandate. See [the Domains-wide authority interpretation](../../../02_Domains/README.md).
