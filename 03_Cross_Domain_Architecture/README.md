# Cross-Domain Architecture

**Status:** V1.3 ACTIVE CROSS-DOMAIN ARCHITECTURE

> **Cross-Domain Function != Cross-Domain Authority**

> **Preserve Developmental History; Index The Living Result.**

## Architectural boundary

Cross-domain architecture may represent dependencies, coordinate interfaces, preserve externally owned state, route review, compare bounded states, preserve provenance and expose unresolved ownership/completeness questions.

It does not automatically gain authority to resolve domain substance, override constitutional constraints, manufacture permission/authority, adjudicate disputes merely because they cross domains, or centralise semantic ownership.

> **Integration Visibility != Substantive Ownership**

> **Coordination != Adjudication**
