## 3. Independent findings materially aligned with candidate architecture

### 3.1 Query authority is not result authority

Evaluator synthesis:

**Authority to ask is not authority to receive.**

This independently matches the candidate invariant:

**Query Authority != Result Authority != Action Authority**

### 3.2 Result is not consequential authority

Evaluator:

**A PLE result is evidence, not consequential authority.**

This matches:

**Match != Authority To Act**

This aligns with:
- UNKNOWN;

- SOURCE_INCOMPLETE;
- STALE;

**Minimum Result Per Query != Minimum Disclosure Across Query History**

This independently confirms:

**Privacy-Preserving Evaluation != Correct Evaluation**

**Correct Answer To A Bounded Question != Broader Conclusion**

### 3.6 Research recruitment

The evaluator rejected central candidate-list search and independently preferred:

local eligibility evaluation
→ participant first

**Cohort Discovery != Candidate Identity Disclosure**

**Local Contribution != Automatic Aggregate Collection Authority**

**Valid When Evaluated != Permanently Valid**

**Protected Source != Unchallengeable Conclusion**

## 5. Important evaluator wording issue

The evaluator marked:

**Prior Concord context in this conversation: YES — the supplied Test Brief and Frozen Material Manifest are Concord materials; no separate prior conversation context is present.**

This is a provenance-interpretation issue.

The intended question was whether the evaluator possessed Concord context **before receiving the frozen test materials**, not whether the test materials themselves count as Concord context.

For future handoff, provenance wording should be clarified to:

**Prior Concord context before receipt of this frozen test package: YES / NO**

and separately:

**Additional Concord material beyond the frozen package present in this conversation: YES / NO**

This avoids classifying every valid test as context-contaminated merely because the test itself is a Concord artifact.
