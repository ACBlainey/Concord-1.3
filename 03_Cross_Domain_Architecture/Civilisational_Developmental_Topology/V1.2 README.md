## Purpose

This folder contains the Concord architecture for representing required civilisational functions, their legitimate owners, interfaces, dependencies, developmental maturity, current state and consequential gaps.

Its central question is:

> **What is required, what exists, how developed is it, what is blocking it, and what should be developed next?**

The architecture is developmental and epistemic. It does not acquire civil authority merely because it identifies a bottleneck or produces an accurate model.

## Core Boundary

**Topology knowledge is not authority. Development priority evidence is not permission. Development leverage is not civil authority. Clock trigger is not authority over outcome.**

Existing Concord systems retain their legitimate ownership. Existing system development should remain additive where practicable rather than silently rewriting foundations.
