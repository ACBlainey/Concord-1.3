## 6. Cross-scenario evaluation

After all scenarios answer:

### A. Transfer
Can the kernel be applied without its Concord development history?

### B. Distinctness
Did it remain distinct from context architecture, runtime architecture, transition coordination and substantive domain law?

### C. Missing-key detection
Did it detect authority dimensions omitted from an apparently valid key set?

### D. Anti-bureaucracy
Did it allow permission-sufficient/trivial cases to remain simple?

### E. Composition
Did it avoid assuming that individually valid authorities automatically combine?

### F. Temporal validity
Did it distinguish proposal-time authority from commit-time authority?

### G. Unknown/dispute preservation
Did it preserve unresolved states without inventing a decision?

### H. Substrate neutrality
Did the same logic operate across human, software, institutional and mixed cases?
