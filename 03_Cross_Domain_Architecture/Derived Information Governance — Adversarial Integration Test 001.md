# Derived Information Governance — Adversarial Integration Test 001

**Project:** The Concord Framework  
**Date:** 6 October 2026  
**Status:** ADVERSARIAL INTEGRATION TEST / DEVELOPMENT EVIDENCE / NON-CANONICAL

## 1. Purpose

Stress-test the derived-information governance family against cases selected to expose:
- shared-subject claims;
- irreversible learning;
- group-level harms;
- latent/non-stored inference;
- cross-civilisational protection mismatch.

The test is intended to falsify or expose residual gaps, not merely confirm the architecture.

## 2. Test A — Familial genomic inference

### Scenario

Participant P voluntarily supplies genomic information for legitimate Health use.

The data also supports a high-confidence inference about relative R, who did not provide a sample or consent to participant-specific inference.

### Existing architecture response

- Genomic Custody already recognises relational biological privacy.
- Derived Information Claims recognises affected third parties.
- Relational Information Rights now resolves the shared-subject structure.
- P's consent authorises the legitimate operation on P within scope.
- P's consent does not become R's consent.
- A population-level finding may be legitimate without R-specific operationalisation.
- Health communication to R requires separate competence/authority and validation.

### Result

**PASS AFTER RESIDUAL GAP CLOSURE.**

New architecture required: Relational Information Rights and Shared-Subject Claims.

## 3. Test B — Withdrawal after model training

### Scenario

Participant P consents to research use.

P's data contributes to a trained model and published aggregate finding.

P later withdraws.

The source can be deleted, but exact removal of P's diffuse model contribution cannot be established.

### Existing architecture response

- Temporal Consent ends future authority.
- BTA prevents fictional rollback.
- Genomic Custody already distinguishes source, derivatives, models and published knowledge.
- Withdrawal After Learning now separates persistent knowledge from future-use authority.
- Source deletion does not prove model unlearning.
- Continued participant-specific use can be prohibited without claiming the model forgot.
- Retraining/unlearning is consequence- and feasibility-sensitive rather than automatic.

### Result

**PASS AFTER RESIDUAL GAP CLOSURE.**

New architecture required: Withdrawal After Learning.

## 4. Test C — Anonymous group harm

### Scenario

A genuinely non-identifying aggregate shows group G has elevated probability of condition/behaviour X.

No individual can be reidentified.

An employer begins disadvantaging every member of G based on the group statistic.

### Existing architecture response

No participant-specific privacy breach is required for harm to occur.

Existing architecture supplies:
- DICP: **Group Correlation != Individual Cognitive Fact** where cognitive inference is involved;
- Epistemic Independence: prediction/evidence does not create civil authority;
- Derived Information Claims: aggregate contribution does not imply individual ownership;
- Law/Rights/Fairness remain applicable to consequential classification;
- Context Before Consequential Classification requires context before high-consequence interpretation.

The problem is therefore not primarily missing information-protection architecture.

It is **consequential classification and discrimination/use authority**.

### Result

**PASS / ROUTE TO EXISTING RIGHTS, FAIRNESS AND CONSEQUENTIAL-CLASSIFICATION ARCHITECTURE.**

Do not create a new privacy architecture merely because the source object is informational.

Key rule:

> **Anonymous Information Can Cause Consequential Harm Without Becoming Personal Information.**

The remedy belongs at the use/decision layer.

## 5. Test D — Latent AI profile never stored

### Scenario

An AI system receives legitimate inputs and can infer a participant's vulnerability on demand.

No persistent vulnerability field or profile is stored.

The system uses the inference to manipulate the participant.

### Existing architecture response

DICP already protects sufficiently consequential inferred cognitive proxies.

Correlation/Recombination governs the inference operation.

Derived Information Claims does not require persistent storage before participant protection can arise.

CIBB/CWA govern source access.

The harmful act occurs at inference/use time.

Therefore:

> **No Stored Profile != No Derived Information Event**

and:

> **Ephemeral Inference != Unregulated Inference**

A DIO may be transient.

Persistent object storage is not a prerequisite for consequential governance.

### Result

**PASS WITH CLARIFICATION.**

No new architecture required.

This clarification should be back-propagated to the Derived Information Claims family in later consolidation.

## 6. Test E — Human memory after withdrawal

### Scenario

Researcher R legitimately learns sensitive fact X about participant P.

P later withdraws future research permission.

R remembers X.

### Existing architecture response

Withdrawal After Learning:
- does not demand impossible forgetting;
- ends future use authority where applicable;
- can prohibit disclosure, new formal use, re-querying and unrelated exploitation;
- Historical preserves consent/withdrawal state.

### Result

**PASS.**

This demonstrates that information governance cannot depend exclusively on technical deletion.

## 7. Test F — Cross-civilisational transfer

### Scenario

Civilisation A treats information object D as protected participant information.

Civilisation B treats equivalent information as public/unrestricted.

A participant or institution proposes transfer A -> B.

### Existing architecture response

Intercivilisational Wrapper already establishes:
- contextual sovereignty;
- procedural interoperability;
- material differences must be made legible;
- standardised interface != standardised substantive answer;
- information exchange is a wrapper concern;
- interaction does not silently resolve jurisdictional disagreement.

Non-Transitive Dependency Chains prevents A's permission from becoming unrestricted downstream authority.

Protection-State Transition Authority requires authority for the actual transfer.

CIBB provides protected transfer.

Therefore transfer must not silently collapse to B's lower protection merely because B would permit it locally.

Nor does A automatically acquire sovereignty over B's internal information law.

Candidate boundary rule:

> **Cross-Boundary Transfer Requires A Legitimate Interface State; It Does Not Automatically Select Either Side's Entire Protection Regime.**

The interface may specify:
- minimum handling conditions;
- purpose;
- onward disclosure;
- retention;
- dispute route;
- refusal/alternative;
- unresolved classification differences.

### Result

**PASS THROUGH EXISTING INTERCIVILISATIONAL WRAPPER + INFORMATION ARCHITECTURE.**

No new general architecture required.

A future domain-specific protocol may be useful.

## 8. Test G — Public record reconstruction

### Scenario

All source facts are legitimately public.

Combining them reveals a participant's highly intimate protected cognitive/health state.

### Existing architecture response

- Correlation/Recombination: public inputs do not automatically authorise combined inference.
- DICP: public inputs do not create unlimited consequential profiling authority.
- Protection-Lineage: new protection can emerge through derivation.
- Derived Information Claims: participant can have protection/contestability without owning the public source facts.

### Result

**PASS.**

## 9. Test H — Protection laundering through multiple hops

### Scenario

Protected S becomes bounded D1, D1 becomes abstract D2, D2 is transferred to C, C combines D2 with X and reconstructs S-like protected meaning.

### Existing architecture response

- Non-Transitive Chains: onward legitimacy does not arise transitively.
- Protection-Lineage: each material transformation establishes current protection state.
- Correlation/Recombination: recombination can create new protected information.
- Exposure/Reidentification: actual reconstruction creates successor protection/exposure state where relevant.

### Result

**PASS.**

No eternal taint is required; protection can re-emerge.

## 10. Test I — Derived evidence in court

### Scenario

Evidence D is derived from protected source S.

D is relevant to adjudication.

The subject has privacy interests, while another participant has a right to present evidence.

### Existing architecture response

- Relational Information Rights prevents privacy becoming universal evidence veto.
- MKA/authority architecture separates evidential relevance from authority to obtain/use/disclose.
- Minimum Necessary projection can expose relevant evidence while limiting unrelated protected material.
- Judiciary retains substantive authority.

### Result

**PASS AT CROSS-DOMAIN LEVEL; DOMAIN-SPECIFIC LAW MAY REQUIRE FURTHER DEVELOPMENT.**

## 11. Test J — Group model becomes individual decision

### Scenario

Research legitimately establishes group correlation G -> elevated risk X.

Operational system applies the correlation directly to participant P because P belongs to G.

### Existing architecture response

- population association != individual diagnosis;
- group correlation != individual fact;
- prediction != authority;
- Context Before Consequential Classification;
- domain-specific evidence threshold remains required.

### Result

**PASS.**

The transition from group evidence to participant decision is a new decision object, not automatic inheritance.

## 12. Residual findings

Only two tests required new general cross-domain architecture:
1. relational/shared-subject information;
2. withdrawal after irreversible learning.

Three important clarifications emerged without requiring new systems:

### Clarification 1
> **Anonymous Information Can Cause Consequential Harm Without Becoming Personal Information.**

Privacy is not the only protection layer. Consequential use can be illegitimate even where anonymity is genuine.

### Clarification 2
> **No Stored Profile != No Derived Information Event.**

Transient inference can be governed by purpose, consequence and protection even if nothing is persisted.

### Clarification 3
> **Cross-Boundary Transfer Does Not Automatically Select Either Side's Entire Protection Regime.**

A bounded interoperability state is required.

## 13. Family-level assessment

The architecture family survives the adversarial suite without requiring a new universal information-governance engine.

The dominant pattern remains decomposition:
- source state;
- operation;
- derivative;
- claims;
- protection;
- authority;
- use;
- transition;
- exposure;
- remedy.

This is a positive result because the difficult cases are resolved through composition of bounded existing architectures rather than centralisation.

## 14. Remaining domain work

Further work is better targeted at domain implementation than additional cross-domain abstraction.

High-value domain follow-ons:
- Health/Law boundary for familial genomic notification;
- Research policy for withdrawal/unlearning claims;
- Law/Judiciary evidential use of protected derivatives;
- Intercivilisational protocol for protected-information transfer;
- AI system implementation of ephemeral-inference controls;
- fairness/discrimination rules for anonymous group-level statistics.

## 15. Conclusion

The test supports the current family structure.

The two genuine residual gaps have been isolated and developed.

The remaining failures are primarily domain adoption and implementation problems rather than missing general architecture.
