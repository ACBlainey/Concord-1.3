## Current architecture

`Spatial and Developmental Planning — Basic Operating Architecture 001.md`

The architecture treats planning as bounded coordination of materially interacting uses of **space and time**, rather than general control of land or participants.

Core distinctions include:

> **Permissible Activity != Permissible Everywhere**

> **Spatial Overlap != Contextual Merger**

> **Co-location != Shared Authority**

> **Development Presence != Environmental Harm**

> **Permission To Build != Unlimited Future Use Authority**

> **Affected Standing != Decision Sovereignty**

The planning object is explicitly three-dimensional and temporal. Surface, subsurface, elevated and future/successor uses may be distinct contexts connected through controlled interfaces.

Candidate lifecycle:

**Need / Proposal → Context and Existing-State Mapping → Interfaces / Externalities / Alternatives → Bounded Decision → Implementation → Monitoring → Adaptation / Review → Successor Use / Retirement**

Major unresolved work remains around settlement planning, housing, transport, detailed permission procedure, property/compulsory-acquisition interfaces, infrastructure corridors, planning finance and off-world planning.
