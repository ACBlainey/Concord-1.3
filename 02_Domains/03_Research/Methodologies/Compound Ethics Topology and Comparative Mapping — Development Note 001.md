# 1. Purpose

Unified Paths now contains ethical material at several different resolutions:

**source passage → extracted proposition → normalised principle → compound/domain principle → higher-order function → compressed root**

A flat catalogue obscures these relationships.

This Development Note defines a method for constructing a **Compound Ethics Topology** that preserves:
- source provenance;
- abstraction level;
- parent/child relations;
- multi-root relations;
- disagreement and uncertainty;
- tradition-specific residuals;
- and the distinction between ethical derivation and Concord architecture.

The immediate object of this work is the **Unified Paths evidence base**.

It is not a replacement Ethical Kernel for canonical Concord.

# 3. Existing Evidence

The Compound Ethics idea is no longer purely speculative.

The Ten Commandments comparison already produced an explicit resolution ladder:

- L0 — minimal ethical root;
- L1 — universal functional attractor;
- L2 — domain principle;
- L3 — concrete behavioural rule;
- L4 — institutional/procedural implementation.

Its upward trace found that multiple concrete commands compress toward fewer roots.

Its blind downward regeneration test found that several secular behavioural functions could be regenerated by applying compressed ethical roots to recurring domains.

The later ethical-topology hypothesis proposed:

**ethical primary → stable intersection → domain principle → institutional function → concrete implementation**

These results support further formalisation, but do not prove that all ethics have this topology or that a unique topology exists.

# 4. Research Question

> **Can the Unified Paths corpus be represented as a provenance-preserving network in which compound ethical principles arise from defensible relations among more compressed ethical functions and contextual conditions?**

Secondary questions:

- Can one compound principle have several root parents?
- Can one root generate multiple compound principles?
- Are some apparent compounds actually operators or contextual conditions?
- Do traditions partition the same ethical function differently?
- Can disputed mappings survive without forced resolution?
- Can downstream principles be regenerated from upstream roots plus context?
- Does the topology remain intelligible in machine-readable form?

---

# 5. Proposed Resolution Model

Use the existing ladder provisionally, but do not force every item into it.

## E0 — Source Evidence

Text, narrative, proverb, command, teaching or other admissible source unit.

## E1 — Extracted Ethical Proposition

The smallest contextually sufficient ethical proposition supported by the source.

## E2 — Normalised Principle

A semantically normalised expression suitable for comparison while preserving provenance.

## E3 — Compound / Domain Principle

A principle whose function appears to depend on:
- several ethical parents;
- a root plus a recurring domain condition;
- or both.

## E4 — Higher-Order Ethical Function

A broader recurring ethical function or attractor.

## E5 — Minimum-Stable Root

The most compressed ethical function retained by the relevant experiment.

This numbering is local to this methodology and must not be confused with Unified Paths experiment labels E2, E3, etc.

Not every ethical item must occupy every level.

---

# 6. Compound Relation

A candidate compound principle can be represented as:

**C_j = f(P_1, P_2, ..., P_n ; D_1, D_2, ..., D_m)**

where:
- P = parent ethical functions;
- D = domain/context conditions.

Example already suggested by the Decalogue work:

**Truth × Non-Harm + contested testimony → evidential integrity constraint**

The important feature is that context participates in generation.

Ethical roots alone may underdetermine the downstream rule.

---

# 7. Parent/Child Test

A relation should not be recorded merely because two principles sound related.

For candidate parent P and child C, ask:

1. Does P constrain or generate a material part of C's function?
2. If P is removed, is some essential part of C lost?
3. Can C be explained more parsimoniously by another parent?
4. Is the relation direct or mediated through another principle?
5. Does the relation depend on a domain condition?
6. Is the mapping source-supported, derivational, interpretive or speculative?
7. Would an independent classifier plausibly reproduce the relation?

Candidate states:
- DIRECT
- COMPOUND
- MEDIATED
- CONTEXT-DEPENDENT
- PARTIAL
- DISPUTED
- UNKNOWN
- REJECTED.

---

# 8. Root, Operator and Condition Separation

Later Unified Paths experiments repeatedly showed that not every recurrent ethical feature should become a root.

The map must therefore distinguish:

**Root** — minimum-stable ethical function.

**Operator** — transforms, calibrates or applies ethical relations, e.g. proportionality, recursion, self-regulation or context-sensitive balancing where supported.

**Condition** — circumstance under which a relation becomes salient, e.g. scarcity, dependency, uncertainty, asymmetry, conflict, developmental difference.

**Compound Principle** — ethical relation produced through roots/functions operating under conditions.

**Implementation** — mechanism or institutional form used to realise a principle.

Failure to separate these categories would artificially inflate the root kernel.

# 11. Bidirectional Testing

A useful topology should support both directions.

## Upward Compression Test

**Source / concrete principle → candidate parents → higher function → root**

Question:

> Does compression preserve the ethically material content?

## Downward Regeneration Test

**Root(s) + conditions → predicted compound/domain principle**

Question:

> Can the downstream function be regenerated without having used the target principle to construct the parent relation?

The Ten Commandments project provides a preliminary example of both directions.

---

# 12. False Compression

A map can appear elegant because distinctions have been erased.

Warning signs:
- many principles map to one root only by losing essential content;
- tradition-specific obligations disappear as “context”;
- positive duties are absorbed into negative restraints without functional recovery;
- theological/covenantal content is treated as secular ethics despite residual meaning;
- different concepts are merged because English translations sound similar.

Every compression should therefore preserve a **residual field**.

Residual ≠ failure.

Residual may indicate:
- tradition-specific content;
- a missing ethical parent;
- an operator;
- a contextual condition;
- an incorrect compression;
- or a genuinely additional structure.

---

# 13. False Decompression

The reverse danger is generating whatever one already expects.

A root such as Non-Harm can be used rhetorically to justify almost anything if context and inference are unconstrained.

Controls:
- freeze target domain;
- state derivation steps;
- state required contextual premises;
- generate before viewing target where possible;
- preserve failed regenerations;
- compare independent classifiers;
- distinguish direct derivation from plausible compatibility.

**Compatibility ≠ Derivation.**

# 17. Machine-Readable Representation

A future implementation could use a graph dataset where each node and edge carries:
- stable ID;
- provenance;
- experiment;
- abstraction level;
- relation type;
- confidence state;
- disputed status;
- source locator.

The graph should permit queries such as:
- show all principles descending from U3;
- show all compounds with U2 + U6 ancestry;
- show all E8 principles that map ambiguously to U1–U8;
- show all residuals that resist compression;
- show all downstream rules supported by three or more independent experimental kernels;
- show disagreements among classifiers.

The machine representation must never hide uncertainty for the sake of graph cleanliness.

---

# 18. First Bounded Pilot

Do not map the entire Unified Paths corpus first.

Select a small, high-information sample containing:
1. one apparently single-root principle;
2. one clear multi-root compound;
3. one context-dependent principle;
4. one tradition-specific residual;
5. one disputed/ambiguous mapping;
6. one principle already used in a downward-regeneration test.

For each:
- reconstruct provenance;
- assign resolution;
- propose parent relations;
- perform removal/loss tests;
- attempt downward regeneration;
- record disagreement.

Then assess whether the node/edge schema is adequate.

---

# 19. Validation Criteria

The pilot succeeds only if the representation can preserve simultaneously:

1. source provenance;
2. abstraction differences;
3. multi-parent relations;
4. context;
5. operators;
6. uncertainty/dispute;
7. residual content;
8. upward compression;
9. downward regeneration;
10. frozen-experiment identity.

A visually tidy graph that loses any of these is not a successful topology.

# Conclusion

Unified Paths increasingly suggests that ethical structure is not best represented as a flat list.

A more adequate candidate model is:

**source → proposition → normalised principle → compound/domain relation → higher-order function → root**

with branching, multiple parents, operators, context and residuals preserved.

The hypothesis remains testable rather than assumed.

Most importantly, this research must retain its lineage:

> **Blainey's Laws remain the Ethical Kernel from which canonical Concord was developed. U1–U8 remains the later Unified Paths comparative kernel used here as an experimental research object.**

The value of comparing the two depends on not confusing them.
