# 11. State Map Constraints on Clock Ordering

The Clock must obey:

1. **High connectivity ≠ automatic priority.**
2. **Development leverage ≠ civil authority.**
3. **PARTIAL ≠ urgent.**
4. A known severe exposed consequence may override infrastructure sequencing.
5. A dependency-blocked target should normally wait for its blocker unless independent mitigation is necessary.
6. UNKNOWN exposure can justify investigation before development.
7. Existing active work should not be redundantly selected.
8. Retest may close a deficit without new architecture.
9. The queue may validly output NO SUBSTANTIVE DEVELOPMENT YET if prerequisite/retest/investigation work dominates.
