# 2. What L2-03 Requires

For this retest, a minimally sufficient shared civil reference must allow different systems or agents to:

1. refer to the same civil function or relation without requiring identical internal models;
2. distinguish function identity from implementation;
3. preserve provenance and uncertainty;
4. represent disagreement rather than silently collapse it;
5. identify current dependency/state relationships;
6. support correction and supersession;
7. avoid creating a sovereign canonical observer;
8. remain translatable into other representations.

A shared civil reference is therefore not identical to shared belief.

# 5. Is Semantic Representation a Remaining Blocker?

Not for the minimum bounded function.

The existing topology already gives systems a common structural vocabulary sufficient to identify:

- which civil function is being discussed;
- which relation is asserted;
- current state;
- evidence/provenance fields;
- uncertainty/dispute;
- version/change state.

A mature semantic-equivalence layer is required for **heterogeneous meaning translation**, but that is a stronger function than the minimum shared civil reference.

Treating semantic equivalence as a prerequisite for any shared reference would unnecessarily block useful operation.

Therefore:

**semantic representation remains a developmental dependency, not a complete blocker.**
