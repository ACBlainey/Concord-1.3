# 1. Purpose

This document begins the mathematical formalisation of the V1.2a Concord fork.

The objective is not to prove an attractor. It is to convert the qualitative structure already generated by the frozen experiment into a reproducible network representation supporting visualisation, root-dependence analysis, redundancy analysis, architectural-distance measures, failure propagation, recoverability analysis, cross-fork comparison and future attractor testing.

V1.2a is not a tree in which eight roots each generate one system. The same roots participate in multiple architectures, and each architecture is generally generated by several interacting roots.

# 3. Ordinal Activation Encoding

The frozen derivations used qualitative rather than pre-specified numeric activation language. For exploratory mathematics:

- 0.0 — not materially activated
- 0.5 — weakly active
- 1.0 — active / conditionally active
- 1.5 — moderately active
- 2.0 — strongly active
- 2.5 — dominant / strongly active
- 3.0 — dominant

These are ordinal encodings, **not measured causal coefficients**. A weight of 2 is not claimed to be twice a weight of 1.

EKC-08 is special. Its full derivation deliberately used a U1–U7 ablation followed by U8 reintroduction rather than a standard eight-root activation table. Therefore v0.1 does not fabricate U1–U7 scores for A8. U8 is encoded as 3 because the full derivation makes it the direct experimental variable; the other A8 cells remain NA pending a separate justified coding pass.

# 6. Root Co-Activation

For pairwise coded architectures define raw co-activation:

[
P_{ik}=\sum_j w_{ij}w_{kj}.
]

Because raw values are strongly influenced by overall activation magnitude, use cosine-normalised co-activation for structural comparison:

[
S_{ik}=\frac{\mathbf{u_i}\cdot\mathbf{u_k}}
{\|\mathbf{u_i}\|\|\mathbf{u_k}\|}.
]

- U1–U6: 0.989
- U2–U6: 0.986

The very high U1/U2/U3/U6 similarities support the predicted central cluster, but the network is generally dense. The result is better described as overlapping ethical fields than isolated modules.

# 7. Architecture State Vectors

Each architecture can be represented as an eight-dimensional root vector:

[
\mathbf{a}_j=[w_{1j},w_{2j},...,w_{8j}].
]

For example:

[
\mathbf{a}_9=[3,3,3,2,2,3,1,2]
]

for Emergency Architecture, and

[
\mathbf{a}_{10}=[3,3,3,1,1,3,1,2]
]

for Intercivilisational Architecture.

For complete vectors, exploratory architectural similarity can be:

[
S_{jk}=\frac{\mathbf{a}_j\cdot\mathbf{a}_k}
{\|\mathbf{a}_j\|\|\mathbf{a}_k\|}
]

with distance

[
D_{jk}=1-S_{jk}.
]

Because the source weights are ordinal, all such results require sensitivity analysis under alternative monotonic encodings.

# 8. Multilayer Civilisational Model

The incidence graph is only the first layer. V1.2a is better represented as a coupled multilayer network:

[
\mathcal{C}(t)=
\mathcal{E}\otimes
\mathcal{F}\otimes
\mathcal{A}(t)\otimes
\mathcal{X}(t)\otimes
\mathcal{R}(t)\otimes
\mathcal{G}(t)
]

where:

- (\mathcal{E}) — ethical-root topology;
- (\mathcal{F}) — required-function topology;
- (\mathcal{A}) — selected architecture/mechanism topology;
- (\mathcal{X}) — failure/exposure topology;
- (\mathcal{R}) — safeguard/resilience topology;
- (\mathcal{G}) — generative/invention topology.

The tensor symbol currently denotes coupled layers conceptually, not yet a specified tensor-product implementation.

# 10. Need-to-Opportunity Feedback

The generative layer introduces:

[
P_t\rightarrow N_t\rightarrow G_t\rightarrow O_t\rightarrow I_t\rightarrow A_{t+1}\rightarrow P_{t+1}
]

where participant experience (P) generates need signals (N), recognised capability gaps (G), open development opportunities (O), candidate inventions (I), and changed architecture (A).

New architecture changes who can participate and what needs become visible. Need discovery is therefore recursive.

# 11. Failure and Resilience Dynamics

For mechanism (m) encountering failure (x):

[
m_t+x_t\rightarrow s_{t+1}
]

where (s) is a safeguard.

But safeguards can themselves fail:

[
s_{t+1}+x'_{t+1}\rightarrow s'_{t+2}.
]

Where a safeguard's costs or capture exceed its legitimate function, replacement or removal is also possible.

Thus:

[
Architecture\rightarrow Failure\rightarrow Safeguard\rightarrow SafeguardFailure\rightarrow Revision\rightarrow\cdots
]

This is the mathematical expression of stored failure knowledge accumulating into resilience architecture.

# 12. Recoverability

For continuity, define a directed dependency graph:

[
G_D=(F,E_D)
]

where an edge (f_i\rightarrow f_j) means recovery of function (f_j) materially depends on (f_i).

A civilisation is not recoverable merely because descriptions survive.

A first scenario-specific measure is:

[
\rho=
\frac{\text{recoverable critical functions}}
{\text{identified critical functions}}.
]

Later models should weight criticality and model correlated dependency failure.

# 13. Root Redundancy and U8

EKC-08 shows why deletion alone is insufficient.

For root (U_i), define mechanism recoverability after ablation:

[
R_i=
\frac{|M(U\setminus U_i)\cap M(U)|}{|M(U)|}.
]

High (R_i) does not prove a root unnecessary.

An orientation term (O_i) is also required for changes in:

- directness;
- scope;
- integration;
- default priority;
- temporal horizon;
- behaviour under weak signals.

A future root-independence measure can therefore take the form:

[
I_i=f(1-R_i,O_i).
]

EKC-08 indicates that U8 has substantial mechanism recoverability while retaining non-trivial orienting/compressive value.

# 14. Architectural Basin / Attractor

Suppose different kernels or reasoners produce trajectories:

[
\mathcal{A}^{(1)}_0\rightarrow\mathcal{A}^{(1)}_1\rightarrow\cdots
]

[
\mathcal{A}^{(2)}_0\rightarrow\mathcal{A}^{(2)}_1\rightarrow\cdots
]

under sufficiently comparable problem environments.

Let (d(\mathcal{A},\mathcal{B})) be a defined architectural distance.

A candidate basin (B) exists if materially different initial conditions repeatedly develop into a bounded region:

[
d(\mathcal{A}^{(k)}_t,B)<\epsilon
]

for multiple sufficiently independent trajectories.

A stronger attractor claim additionally requires evidence that perturbations away from the region tend to return toward it.

V1.2a has **not** demonstrated that. It supplies one contaminated counterfactual fork with ten domain observations and repeated high-level convergence.

The correct present term is therefore:

# **Candidate Architectural Basin**

- (D_E) — ethical-topology distance;

Coefficients must not be selected to manufacture convergence. Sensitivity analysis across plausible coefficient ranges is required.

# 16. Candidate Measures

Future formalisation should calculate:

1. **Root centrality** — breadth/strength of root participation.
2. **Root co-activation** — recurring ethical intersections.
3. **Architecture similarity** — similarity of root profiles.
4. **Functional bridge centrality** — functions connecting architectural regions.
5. **Dependency depth** — prerequisite layers required by a function.
6. **Single-point fragility** — critical dependence on one node/path.
7. **Correlated redundancy** — hidden common dependencies among apparently redundant paths.
8. **Contestability reach** — whether consequential power has a viable correction route.
9. **Repair reach** — whether failures can propagate into repair.
10. **Exit cost** — critical function lost when an institution/relationship ends.
11. **Regeneration distance** — dependency transitions needed to reconstruct function.
12. **Generative openness** — routes from participant need to independent candidate invention.

These are definitions/proposals, not validated metrics.

# 19. Result of v0.1

The first formal model supports four provisional conclusions.

1. **The topology is dense.** The roots behave as overlapping fields rather than isolated policy domains.
2. **U1/U2/U3/U6 form a candidate central co-activation cluster** in the present sample.
3. **U4/U5/U7/U8 strongly reshape specific problem classes** rather than behaving as merely peripheral roots.
4. **The mature civilisational state cannot be represented by the ethical incidence graph alone.** Failure, resilience, invention and environmental layers are mathematically necessary if the model is to represent the developmental findings of V1.2a.

The next operation is to generate the v0.1 topology image directly from this model, then extend the formalisation to architecture similarity, cross-system functional nodes and the first explicit basin-test protocol.
