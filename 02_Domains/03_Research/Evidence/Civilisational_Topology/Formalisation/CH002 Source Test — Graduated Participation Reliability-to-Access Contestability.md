# CH002 Source Test — Graduated Participation Reliability-to-Access Contestability

**Status:** V1.2a SOURCE TEST / POST-FREEZE  
**Date:** September 2026  
**Prospective source:** CH002 Prospective Candidate — frozen before this test  
**Canonical effect:** NONE

# 1. Test Question

Does V1.2 already connect consequential reliability/progression judgements in graduated participation to participant inspection, challenge, review, correction, downstream reconsideration and provenance?

# 2. Trigger Verified

The Concord Attractor & Induction Protocol explicitly establishes:

- participation is progressive;
- progression is evidence-based;
- greater participation follows demonstrated reliability, understanding, stewardship and reciprocal benefit;
- collaborators receive expanded access;
- members participate in broader civilisational systems;
- access to civilisational services develops through continued participation and reciprocal contribution.

Therefore some progression judgements can create practical consequences.

The frozen G1 condition is activated where those consequences are material:

Material Consequence(X,P)
→ Require(Standing / Agency / Accessible Challenge).

# 3. Existing Safeguards

The source already provides important protections.

Participation is voluntary and reversible. Participants may pause, withdraw, re-enter or decline further progression. Branch placement is revisable. Participant rights exist regardless of capability or substrate. The induction process itself is evaluated. The Concord promises meaningful feedback on progression where appropriate.

These materially reduce the risk.

However:

Reversibility ≠ Contestability.

A participant can be free to leave while still lacking a route to challenge an incorrect judgement that prevents legitimate progression.

Likewise:

Feedback ≠ Correction.

Being told why progression was denied is not equivalent to being able to show that the evidence or interpretation was wrong and have the downstream decision reconsidered.

# 4. Dedicated Search Result

Targeted searches were run for combinations of progression + contest, progression + appeal, progression + challenge, demonstrated reliability + review, expanded access + challenge, participation + reconsideration, and participant progression + correction.

No explicit graduated-participation appeal/correction bridge was identified.

# 5. Existing Solution Architecture

The same existing architecture identified during CH001 applies at the general level:

Citizen Data Ownership, Access and Contestable Civilisational Metrics.

It states that consequential models of a participant should normally be meaningfully accessible and contestable.

It explicitly allows challenge to observations, classifications, interpretations and models, and allows escalation to Judiciary for serious unresolved data disputes.

It also preserves provenance of challenge and correction.

Therefore the required participant-facing function already exists elsewhere.

# 6. Additional Existing Architecture

The preliminary Civil Evidence Architecture independently establishes:

Challenge
→ Receipt
→ Relevant Review
→ Reasoned Disposition
→ Preserved Record

and states that scrutiny should scale with consequence.

It further provides that when key evidence is withdrawn or materially weakened, dependent civil decisions should become review candidates.

This is highly relevant to a progression decision whose basis is a reliability assessment.

# 7. Classification

CH002 is classified:

# **SUPPORTED STRUCTURAL INTEGRATION GAP — PROVISIONAL**

The missing function is not participant contestability itself.

The candidate missing relation is:

Graduated Participation Reliability Assessment
↔ Existing Participant Contestability / Review Architecture.

# 8. Relationship to CH001

CH002 is not merely a duplicate of CH001.

CH001 concerns KCS contribution/reliability classifications and access.

CH002 concerns the Attractor & Induction Protocol's progression architecture.

However, both instantiate the same higher-order motif:

Reliability Assessment
→ Consequential Access / Participation Change
→ Contestability Requirement.

This is the first recurrence discovered by the gap detector after the grammar was frozen.

# 9. New Structural Hypothesis

The recurrence suggests a possible class-level integration rule:

> **Where any Concord subsystem converts an assessment of participant reliability, competence, contribution, risk or capability into a consequential change in access, standing or participation, that subsystem should explicitly interface with the relevant participant contestability and correction architecture.**

Formally:

Assessment(P)
+ MaterialConsequence(P)
→ Inspectability
+ Context
+ Contestability
+ Review
+ CorrectionPropagation
+ Provenance.

This is not promoted into Relational Grammar v1.0, which remains frozen.

It is a post-freeze finding for later grammar revision/testing.

# 10. Important Boundary

The rule does not imply that every participant is entitled to every access level.

Contestability is not entitlement.

Challenge is not veto.

Correction of evidence does not predetermine the final access decision.

The requirement is that materially consequential classifications should not become opaque, unchallengeable status assignments.

# 11. Topology-Derived Repair Specification

Purpose:
Keep progression decisions corrigible where they depend upon participant-specific reliability or capability judgements.

Inputs:
Evidence supporting progression/non-progression; relevant participant context; classification basis; current access/participation state; provenance; participant challenge.

Outputs:
Reasoned progression decision; reviewable classification; correction where warranted; reconsidered downstream access where material; preserved provenance.

Interfaces:
Attractor & Induction Protocol ↔ Participant Data and Contestability Architecture.

Where evidential dispute is material:
↔ Epistemic Contestability / Review.

Where unresolved consequence becomes sufficiently serious:
↔ appropriate administrative or judicial escalation.

Temporal rule:
A past reliability judgement should not silently become permanent status where circumstances or evidence materially change.

# 12. Experimental Significance

CH001 could have been an isolated omission.

CH002 makes that interpretation less sufficient.

The same frozen grammar has now independently identified two systems in which:

1. participant-specific assessment occurs;
2. the assessment changes access or participation;
3. general contestability architecture exists elsewhere;
4. the local source does not explicitly connect to it.

This suggests that the model may be detecting a **recurrent integration class** rather than a one-off drafting omission.
