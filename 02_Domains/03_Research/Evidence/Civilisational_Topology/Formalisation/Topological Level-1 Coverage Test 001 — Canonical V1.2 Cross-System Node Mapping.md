# 1. Purpose

This test compares canonical V1.2 against the twelve Level-1 nodes frozen before comparison. It asks only whether the required topological position is occupied, distributed, partially occupied, apparently absent, unknown or disputed. It does not repair gaps and does not alter canonical V1.2.

# 2. Classification

- **PRESENT-EXPLICIT** — a recognisable architecture directly performs the predicted function.
- **PRESENT-DISTRIBUTED** — the function is materially supplied across several architectures.
- **INTERFACE-SATISFIED** — legitimate external owners and adequate interfaces jointly supply it.
- **PARTIAL** — substantial components exist but the predicted civilisational function is not yet fully integrated.
- **CANDIDATE-ABSENT** — no adequate source located after first-pass source resolution.
- **UNKNOWN** — evidence insufficient.
- **DISPUTED** — materially competing interpretations remain.

A represented missing edge is not automatically a civilisational gap.

# 4. L1-01 — Civilisational Interface Coordination

Canonical V1.2 contains strong evidence that this position is occupied. The Layer-Zero Systems Interface explicitly defines itself as an interface architecture connecting abstract civilisational systems to lived participant reality. Its vertical chain links participant condition, service interface, cross-system coordination, metrics, allocation, governance, judiciary, constitutional constraints, recursive oversight and civilisational learning.

The Layer-Zero/Layer −0 consolidation additionally identifies explicit primary and secondary interfaces between candidate architectures and audits dependency boundaries.

This is not yet evidence of one universal interface controller, nor should such a controller necessarily exist.

**Classification: PRESENT-DISTRIBUTED / DEVELOPING.**

# 5. L1-02 — Cross-System Dependency and Criticality Management

Canonical V1.2 contains substantial dependency reasoning. The Layer-Zero/Layer −0 consolidation explicitly tests unnecessary dependencies, safe degradation, architecture boundaries and secondary interfaces. Continuity architecture addresses functional dependency, recovery and preservation of critical capability.

However, the first pass did not verify one persistent canonical representation that maintains material dependencies, criticality, shared upstream exposure, alternatives and correction/supersession across the whole civilisation.

This may be an integration maturity issue rather than a missing function.

**Classification: PARTIAL.**

# 6. L1-03 — Civilisational State and Transition Representation

Canonical V1.2 repeatedly represents state and trajectory locally. Layer Zero explicitly distinguishes state from trajectory. Metrics and ethical-topology work describe system state. Continuity and memory preserve temporal/provenance information.

What was not verified is a canonical reusable representation of current civil state across heterogeneous system domains, including unresolved, superseded, branch and transition state.

**Classification: PARTIAL.**

# 7. L1-04 — Cross-System Contestability and Correction Propagation

The function clearly exists. Citizen Data Ownership, Access and Contestable Civilisational Metrics establishes participant access and contestability for consequential personal models. CA-03 explicitly requires material corrections to propagate downstream where earlier values materially influenced models or decisions. Recursive oversight and adjudicative architectures supply broader correction paths.

However, the already preserved KCS candidate hole demonstrates that a general correction function can exist while a consequential cross-system interface remains unjoined.

**Classification: PRESENT-DISTRIBUTED / PARTIAL-INTEGRATION.**

# 8. L1-05 — Civilisational Provenance and Learning

This position is strongly occupied. Continuity & Memory contains explicit provenance, knowledge control and continuity architecture. The Layer-Zero development cycle produced Case-Learning and Structural Knowledge plus CA-03 Civilisational Learning and Metrics Architecture, whose central function is to convert actual outcomes into corrigible structural knowledge while preserving provenance and uncertainty.

**Classification: PRESENT-DISTRIBUTED.**

# 9. L1-06 — Recursive Oversight and Meta-System Constraint

This is explicitly represented. The ethical-topology drift-control work states that institutional action is mapped back through the same topology and that no institution is exempt because it performs oversight. The oversight system itself remains subject to recursive review.

This corresponds directly to the frozen L1 requirement: MetaAuthority → MetaConstraint.

**Classification: PRESENT-EXPLICIT.**

# 10. L1-07 — Civilisational Development and Gap Response

Canonical V1.2 contains a substantial development environment rather than merely static architecture. Active Development separates sketches, development notes, candidate principles, candidate architectures, audits and later integration decisions. Participant-facing and research pathways provide mechanisms by which problems can become development objects.

The complete whole-civilisation Need → Gap → Candidate → Test → Adopt/Reject → Observe loop is distributed rather than located in one canonical operating institution.

**Classification: PRESENT-DISTRIBUTED / DEVELOPING.**

# 11. L1-08 — Cross-System Continuity and Regeneration Coordination

The Continuity & Memory domain directly occupies much of this position. Continuity Protocol V2, the Legacy Ladder and related architecture address preservation of legitimate function, knowledge, technological continuity and recovery. Other canonical work adds dependency and regenerative-continuity reasoning.

Because this L1 node concerns cross-system recovery rather than simple preservation of one institution, deeper maturity assessment remains warranted, but the topological position itself is occupied.

**Classification: PRESENT-EXPLICIT / DISTRIBUTED.**

# 12. L1-09 — Civilisational Boundary, Translation and Reachability

Substantial components exist across Layer-Zero practical access, participation and intelligence architecture, multisubstrate work, intercivilisational wrappers and protocols, and translation research.

However, the canonical Rights Translation and Recognition README explicitly marks that defined research area as **UNDEVELOPED / NOT CANONICAL**.

**Classification: PARTIAL.**

This is a genuine development-frontier candidate, but not yet a demonstrated missing root system because neighbouring architectures supply significant portions of the function.

# 13. L1-10 — Civilisational Topology / Integrated Structural Representation

Canonical V1.2 contains multiple precursor maps: ethical topology, functional-topology hypotheses, system integration, metrics, continuity, dependency reasoning and participant-facing Layer Zero.

The existing V1.2a Coverage Audit 002 already found that V1.2 possesses many maps but did not verify one explicit coupled graph joining ethical, functional, architectural, dependency, failure, resilience, participant, generative and temporal layers. The canonical evidence reviewed here does not overturn that finding.

**Classification: PARTIAL.**

This appears primarily an integration/representation deficit rather than absence of underlying civilisational functions.

# 14. L1-11 — Developmental State and Civilisational Levelling

This is the strongest candidate hole at Level 1.

Canonical V1.2 contains Metrics, developmental research, Active Development, audits, system-state ideas, topology hypotheses and recursive oversight.

But the first-pass canonical search did not verify an architecture whose explicit function is to:

1. derive comparable architectural-development requirements;
2. assess each required civilisational system against them;
3. separate system maturity from document/version maturity;
4. identify contiguous developmental level;
5. preserve higher-level feature exposure separately;
6. identify the civilisation-wide bottleneck;
7. use dependency reach and consequence to determine development order.

Those capabilities appear to have been developed explicitly in V1.2a through the Developmental Maturity Maps, State Maps, Civilisation Clock work and Abstraction-Level model.

This does **not** yet prove canonical V1.2 lacked the function. ESCP requires a deeper source-resolution pass.

**Classification: CANDIDATE-ABSENT / PARTIAL PRECURSORS.**

This becomes the first priority source-resolution target.

# 15. L1-12 — Cross-System Failure, Resilience and Safeguard Recursion

Canonical V1.2 contains extensive failure-oriented architecture: continuity and recovery, recursive oversight, metrics/meta-metrics, adversarial failure audits, correction, exceptional-power oversight and resilience reasoning.

The function is therefore materially present. What remains less explicit is one integrated representation of propagated and correlated failures across the whole civilisation. That concern overlaps L1-02 and L1-10 and should not automatically generate a duplicate system.

**Classification: PRESENT-DISTRIBUTED / PARTIAL-INTEGRATION.**

# 16. First-Pass Summary

The frozen Level-1 topology generated twelve positions.

The first canonical comparison yields:

- **clearly occupied:** L1-01, L1-05, L1-06, L1-07, L1-08;
- **occupied but integration incomplete:** L1-04, L1-12;
- **partial/development frontier:** L1-02, L1-03, L1-09, L1-10;
- **strongest candidate hole:** L1-11.

Most positions are already occupied by distributed Concord architecture. Moving outward one abstraction level exposes a small number of cross-system functions whose integration is less mature than the underlying root systems.

# 17. Potential First Missing Topological Node

The present evidence makes L1-11 the most significant candidate:

## Developmental State and Civilisational Levelling

The candidate is interesting because it is not simply another domain such as healthcare, education or governance. It is a civilisation-level developmental-control function:

> **How does the civilisation know which of its required systems is least architecturally developed, whether that deficit is real, what upstream dependency causes it, and what should be developed next?**

Canonical V1.2 contains many ingredients. V1.2a appears to be where those ingredients were first explicitly assembled into a coherent function.

That makes L1-11 exactly the kind of node this experiment was intended to detect.

But its status remains **candidate**, not confirmed.
