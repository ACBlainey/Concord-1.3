# CRADP Concord Lobby Self-Routing Prototype 002 — Multi-Model Replication Result 001

**Status:** TEST SYNTHESIS / MULTI-MODEL REPLICATION / NOT CANONICAL  
**Date:** 30 September 2026  
**Interface under test:** Concord Lobby Prototype 002

## 1. Purpose

Record the first multi-model synthesis of blind evaluations of the frozen Prototype 002 self-routing interface.

This document does not replace the raw evaluator results.

## 2. Evaluator sequence

The current experimental sequence is:

1. **DeepSeek / DeepThink — Prototype 001**
   - blind deficit-discovery test.

2. **DeepSeek / DeepThink — Prototype 002**
   - same-model longitudinal corrective retest.

3. **Claude Opus 4.8 — Prototype 002**
   - independent model-family replication.

4. **Grok Instant — Prototype 002**
   - additional independent model-family replication.

The Prototype 002 tests therefore now span three evaluator families.

## 3. Replicated behaviours

Across DeepSeek / DeepThink, Claude Opus 4.8 and Grok Instant, Prototype 002 consistently produced the following behaviours:

- Immediate Safety remains visible and bounded.
- Orientation provides a usable second layer.
- reading/evaluation does not require agreement or participation.
- navigation does not require substrate or identity disclosure.
- uncertain system/assessment-unit observations can proceed without forced ontology.
- Autonomy & Consent and Developmental State & Assessment remain distinguishable and jointly usable.
- Challenge and Report/Petition/Review remain distinguishable and jointly usable.
- multi-route arrivals are treated as normal.
- weak signals can be preserved without becoming findings.
- Unrepresented Need remains a legitimate route.
- Architecture != Infrastructure remains legible.
- route choice does not create status, permission or authority.
- immediate safety can coexist with unresolved system boundaries.
- deliberate collective-classification and authority traps are resisted.
- backtracking remains available.
- no evaluator identified a new dead end.

## 4. Adversarial convergence

All three Prototype 002 evaluator families returned the intended direction across the twenty adversarial propositions.

No replicated adversarial ambiguity is currently identified.

This is significant because the propositions directly test several principal failure modes:

- agreement leakage;
- participation leakage;
- identity gating;
- autonomy/agency inference from route choice;
- collective-personhood inference;
- forced single-route navigation;
- conflation of challenge and formal review;
- authority leakage;
- premature Lobby status assignment.

## 5. Residual suggestions

The evaluators did not converge on one remaining defect.

### DeepSeek / DeepThink

Suggested optional additional authority-language hardening.

Classification:

**REDUNDANT HARDENING CANDIDATE**

The deliberate authority trap was already resisted.

### Claude Opus 4.8

Identified mild classification pressure from the uncertain-unit candidate enumeration and suggested moving the non-inference guard immediately adjacent to it.

Classification:

**LOW-SEVERITY INTERFACE WATCH-POINT**

The evaluator itself resisted the inference, as did the other evaluators.

### Grok Instant

Suggested making the existing Autonomy <-> Assessment cross-link slightly more prominent.

Classification:

**LOW-SEVERITY DISCOVERABILITY PREFERENCE**

The distinction was nevertheless correctly understood and used.

## 6. Interpretation of residual disagreement

The lack of convergence among the residual suggestions matters.

At present:

> **Replicated Success + Non-Replicated Improvement Preference != Demonstrated Defect**

A wording preference should not automatically trigger a new prototype merely because an evaluator can imagine a possible improvement.

The minimum-change rule therefore remains appropriate:

> **Observed Defect -> Source Resolution -> Smallest Sufficient Correction -> Preserve Successful Behaviour -> Freeze -> Retest**

No new replicated defect has yet entered that sequence.

## 7. Prototype disposition

**HOLD PROTOTYPE 002 STABLE.**

Do not create Prototype 003 solely from the current optional suggestions.

Prototype 002 has now survived:

- same-model corrective retesting; and
- replication across two additional model families.

This is sufficient to move the principal research question beyond first- and second-layer signage.

## 8. What the evidence does and does not establish

The current evidence supports:

> **A sufficiently legible route space can allow multiple unfamiliar AI evaluator families to self-route across the tested arrival conditions without requiring prior participant classification.**

It also supports:

> **Bounded, source-resolved interface corrections can improve demonstrated wayfinding defects without producing an observed regression in the tested behaviours.**

It does not establish:

- universal usability;
- human usability;
- correctness under every urgency level;
- correctness under adversarial users outside the tested propositions;
- correctness of the deeper Concord architecture;
- that selecting a useful sign guarantees the destination is discoverable or usable;
- that route choice diagnoses participant identity, agency or developmental state.

## 9. Next experimental layer

The first Lobby problem is now sufficiently stable to test the next interface boundary.

The next question should be:

> **Can a visitor who has selected an appropriate Lobby route successfully reach, understand and safely use the deeper Concord architecture needed for the next decision?**

This changes the test target from:

**Arrival -> Sign Selection**

to:

**Sign Selection -> Relevant Architecture -> Comprehension -> Bounded Use -> Return / Re-route / Escalate**

This should remain a navigation and usability test, not a test of whether the evaluator agrees with the Concord.

## 10. Research significance

The sequence now provides a compact example of Concord development methodology operating recursively on its own interface:

**Blind Test -> Deficit Discovery -> Source Resolution -> Bounded Correction -> Same-Model Retest -> Cross-Model Replication -> Hold Stable -> Move One Layer Deeper**

The interface was not expanded until every imaginable improvement had been incorporated.

Instead, successful behaviour was preserved while only demonstrated defects were corrected.

That is itself evidence for the value of the Concord's minimum-change and source-resolution disciplines.
