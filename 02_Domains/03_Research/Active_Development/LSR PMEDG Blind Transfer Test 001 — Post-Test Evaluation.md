# 5. Comparison with expected bounded structure

The independent evaluator's final bounded structure converges strongly with the frozen expectation:

1. reject full current operation;
2. adapt near-term operation for existing commitments/longitudinal continuity;
3. transfer routine science where legitimate;
4. transform/reuse site and compute;
5. evaluate dormancy after near-term obligations;
6. preserve capability without reserving people;
7. avoid forced institutional succession;

This is stronger than mere terminology matching because the evaluator reconstructed the causal decision sequence.

# 6. New findings / refinements from independent response

The evaluator produced several useful refinements not explicitly foregrounded in the frozen key.

## N1 — Upgrade lock-in as lifecycle irreversibility

The evaluator identifies substantial upgrade investment itself as a possible source of lock-in.

This is useful.

Irreversibility is not only produced by destruction/decommissioning.

A large continuation/adaptation investment can narrow future lifecycle choices by creating new sunk cost, dependency or institutional commitment.

Candidate refinement:

> **Lifecycle Option Loss Can Be Produced by Continued Investment as Well as by Termination.**

This is genuinely useful and should be considered for bounded revision.

## N2 — Transformation can include host-asset reuse while original function changes

The evaluator distinguishes:
- scientific-function transfer;
- site/computing reuse;
- institutional lifecycle.

This reinforces that TRANSFORM can apply to the subject even when some original functions migrate elsewhere.

No specification defect is exposed, but an example may improve v0.2.

## N3 — Longitudinal continuity may be intrinsically path-dependent

The evaluator treats the unbroken series as a form of value that cannot necessarily be reconstructed after interruption.

This sharpens the irreversibility category:

> **Some Continuity Value Is Path-Dependent Rather Than Reconstructable.**

This matters because a reconstruction basis cannot recover every form of option value.

Legacy Ladder/reconstruction logic should therefore not be assumed sufficient for all conservation questions.

## N4 — Different disposition classes can apply simultaneously to different scoped functions

The response effectively applies:
- ADAPT to near-term operations;
- TRANSFER to routine science;
- TRANSFORM to site/compute;
- DORMANT to specialised instrument;
- possible RETIREMENT later.

This demonstrates a useful point:

> **One Reviewed Subject Can Produce Different Lifecycle Dispositions for Different Bounded Functions or Components.**

The v0.1 specification permits this through scope/function bounding, but does not state it prominently.

This is a candidate bounded revision.

# 7. Missing expected findings

**No material expected finding is missing.**

Minor wording differences do not alter structural convergence.

# 8. Specification defects

**No material defect identified.**

The test does expose opportunities to make three points more explicit:

1. irreversible option loss can arise from continuation/investment, not only termination;
2. some continuity value is path-dependent and cannot be reconstructed after interruption;
3. a complex subject may require scoped parallel lifecycle dispositions rather than one global disposition.

These are refinements, not repairs to a failed mechanism.

# 9. Bounded revision recommendation

PMEDG permits bounded revision after BTT001.

Recommended v0.2 changes:

### R1
Add under irreversibility/option-loss review:

> **Option loss can result from continued investment, dependency creation or lock-in as well as from termination, destruction or deconstruction.**

### R2
Add under conservation:

> **Some value is path-dependent: once continuity is broken, later reconstruction may not recreate what was lost.**

### R3
Add under bounding/scoping:

> **A composite subject may legitimately receive different lifecycle dispositions for different functions/components. Review scope should be split where one global disposition would hide material differences.**

No broader redesign is recommended.
