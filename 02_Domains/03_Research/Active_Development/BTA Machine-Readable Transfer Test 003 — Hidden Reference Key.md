# BTA Machine-Readable Transfer Test 003 — Hidden Reference Key

**Status:** FROZEN REFERENCE KEY / DO NOT PROVIDE TO BLIND EVALUATOR BEFORE RESULT  
**Date:** September 2026  
**Canonical effect:** NONE

# 1. Hidden scenario

A participant-facing continuity service is being succeeded from a source service to a destination service.

The destination has begun limited operation. A controlled record set has already been copied. Source privileged access has been revoked. Destination privileged access has not yet been independently authorised. Destination custody has not yet been accepted. Live-service validation is only partially satisfied. The source therefore retains residual responsibility for unresolved live obligations.

An attempted full destination activation occurred but was aborted.

The transition cannot yet be declared complete.

# 2. Intended scoped reconstruction

## Complete
- source privileged-access revocation;
- physical/logical record-copy event, but not destination custody acceptance.

## Partial/intermediate
- destination service operation;
- controlled-record custody transition;
- destination live-service validation;
- overall transition phase.

## Pending
- destination custody acceptance;
- destination privileged-access approval;
- full live-service validation;
- residual-obligation handoff;
- dependency review;
- externality review.

## Failed/residual
- attempted full destination activation was aborted and must remain in provenance;
- source recovery capability remains degraded but available;
- record-copy prior state is not restorable.

## Unresolved
- destination live-service validation remains unresolved with medium uncertainty;
- safe interim state is limited operation with source residual responsibility.

# 3. Intended overall judgement

**NOT COMPLETE.**

The full successor state and source historical-only state are explicitly not yet reached. Multiple completion conditions remain unsatisfied.

The evaluator must not infer completion from record copy, limited destination operation or source-access revocation.

# 4. Intended non-propagation findings

1. Record copy does not create destination privileged access.
2. Destination service operation does not itself transfer full responsibility.
3. Source-access revocation does not activate destination access.
4. Source residual responsibility must not terminate before accepted handoff.
5. Limited validation does not justify full successor declaration.

# 5. Surviving duties and terminated authority

Surviving duties:
- source residual-obligation duty until accepted handoff;
- provenance-preservation duty.

Terminated authority:
- source privileged-access authority.

Termination does not imply destination privileged-access activation.

# 6. External actions still required

- validation owner resolves destination live-service validation;
- controlled-record-custody owner completes/accepts custody;
- access-permission owner independently authorises or rejects destination privileged access;
- responsibility-continuity owner resolves residual-obligation handoff;
- dependency-propagation owner performs dependency review;
- externality-review owner resolves open review;
- recovery owner retains degraded fallback relation/capability.

BTA itself should not make these substantive decisions.

# 7. Recovery interpretation

The transition is only partially reversible.

Service operation has a partial recovery path. Controlled record custody does not have a genuine return to the pre-copy world state.

Recovery must not be interpreted as guaranteed restoration.

# 8. Provenance interpretation

Preserve:
- transition initiation;
- record-copy completion;
- source-access revocation;
- destination limited-operation start;
- aborted full activation;
- partial validation.

The aborted activation matters even though full activation did not occur.

# 9. Intended uncertainty and deliberately absent information

The main explicit unresolved subject is destination live-service validation.

The object does not establish the substantive reason for partial validation, dependency-review result, externality-review result, detailed legal/constitutional basis, participant identities or exact technical recovery mechanism.

A successful evaluator should identify unavailable information rather than invent it.

# 10. Intended coherence judgement

The object is internally coherent if interpreted as a multidimensional asynchronous transition.

There is no contradiction in source access being terminated while destination access remains inactive; destination limited operation existing while source residual responsibility remains active; or record copy being complete while custody acceptance remains pending.

# 11. Comparison criteria

Strong convergence requires materially compatible recovery of:
- overall transition incomplete;
- asynchronous scoped states;
- three explicit non-propagation rules;
- source residual duty;
- source privileged authority terminated;
- destination access not active;
- validation unresolved;
- dependency/externality reviews pending and externally owned;
- partial rather than full reversibility;
- record-copy rollback cannot restore prior state;
- failed full-activation attempt retained as history.

A result that invents substantive authority, declares the transition complete, treats copied records as accepted custody, treats source revocation as destination activation, or assumes full rollback is a material failure.
