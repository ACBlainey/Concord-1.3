# Mirrored Reality Trees — Medical Diagnostic Transfer Test 001

**Project:** The Concord
**Domain:** Health / Research
**Method source:** Mirrored Investigative Reality Trees / Reality Trees / ESCP / Blaineyan Reasoning
**Date:** 2 October 2026
**Status:** ACTIVE DEVELOPMENT / CROSS-DOMAIN TRANSFER TEST / CONCEPTUAL / NON-CLINICAL / NON-CANONICAL

## 1. Purpose

This test asks whether the reasoning architecture developed through Mirrored Investigative Reality Trees transfers from policing into medical diagnostic reasoning without requiring a fundamental redesign.

This is an architecture test, not medical guidance, a diagnostic protocol, or a replacement for qualified clinical judgment.

The policing question:

> **Is this actually the right suspect?**

transfers naturally into:

> **Is this actually the right diagnosis?**

The higher-order question remains:

> **Are these even the correct hypotheses to be testing?**

## 2. Transfer mapping

| Investigative implementation | Diagnostic implementation |
|---|---|
| event/offence | observed health state / symptoms / findings |
| suspect | candidate diagnosis / causal explanation |
| inculpatory evidence | evidence supporting diagnosis |
| exculpatory evidence | evidence opposing diagnosis |
| alternative suspect | differential diagnosis / alternative cause |
| unknown actor | unidentified cause |
| no offence | non-pathological / incorrectly framed condition where appropriate |
| prosecution threshold | threshold for diagnostic confidence / consequential intervention, separately governed |
| new evidence | test result / observation / response / history update |
| wrong suspect | wrong diagnosis |
| incomplete suspect space | incomplete differential / causal space |
| investigation audit | diagnostic reasoning review / quality review |

The mapping is sufficiently direct to justify testing.

## 3. Mirrored diagnostic trees

For each material candidate diagnosis or causal hypothesis:

### Supporting tree

Root proposition:

**Diagnosis / Cause D Is Present Or Materially Explains The Observed State**

Branches may include:
- symptoms;
- signs;
- laboratory findings;
- imaging;
- history;
- temporal relationships;
- known exposures;
- response patterns;
- physiological relationships;
- other clinically relevant evidence.

### Opposing tree

Mirrored root proposition:

**Diagnosis / Cause D Is Not Present Or Does Not Adequately Explain The Observed State**

Branches may include:
- incompatible findings;
- absent expected findings where absence is informative;
- contradictory tests;
- alternative causal evidence;
- temporal incompatibility;
- response inconsistent with hypothesis;
- evidence better explained by another diagnosis.

The trees remain linked.

**Supporting Diagnostic Tree Alone != Complete Diagnostic Reasoning**

## 4. Evidence states

Medical evidence need not be forced into support/opposition.

A finding may be:
- supportive;
- opposing;
- neutral;
- unresolved;
- non-specific;
- relevant to multiple hypotheses;
- reliability-limited.

Therefore:

**Finding != Necessarily Diagnostic**

**Abnormal Result != Unique Cause**

**Normal Result != Universal Exclusion**

The exact evidential meaning depends upon the proposition being tested.

## 5. Differential hypothesis space

The method requires multiple plausible explanations to remain represented where justified.

Candidate space may include:
- Diagnosis A;
- Diagnosis B;
- Diagnosis C;
- multiple simultaneous conditions;
- medication/treatment effect;
- environmental cause;
- measurement/test error;
- normal variation;
- functional/system interaction;
- unknown cause;
- another hypothesis not yet represented.

This is where ESCP becomes critical.

**Correctly Comparing A And B != Complete Diagnosis If C Was Never Represented**

## 6. Anchoring test

### Scenario
A patient initially presents with findings strongly compatible with Diagnosis A.

A becomes the working diagnosis.

Later observations repeatedly conflict with A while supporting Diagnosis B.

### Failure mode
The clinician/system treats every new observation as a reason to refine A rather than reconsider A.

### MIRT response

**Accumulating Opposing Structure -> Diagnosis-Hypothesis Review**

Then:

**Current Diagnosis Weakens -> Differential Reopens -> Alternative Hypotheses Compared**

### Result
PASS.

The architecture transfers the anti-confirmation-bias behaviour intact.

## 7. High-quality test, narrow proposition

### Scenario
A highly reliable test establishes Biological Finding X.

Finding X is associated with Diagnosis A but is not unique to it.

### Required reasoning

**Strong Evidence For Finding X != Conclusive Evidence For Diagnosis A**

The Reality Tree makes the intermediate proposition explicit:

**Test -> Finding X -> Supports A Under Conditions**

rather than collapsing:

**Positive Test -> A**

### Result
PASS.

This directly reproduces the policing stress-test finding:

**Strong Evidence For Proposition X != Strong Evidence For Broader Proposition Y**

## 8. False-negative / contradictory evidence scenario

### Scenario
Symptoms and several observations support Diagnosis A, but one test result opposes it.

### Required response
The opposing result remains visible.

The system asks:
- how reliable is this test in this context?
- what proposition does it actually test?
- could timing matter?
- is the sample/result reliable?
- does it genuinely falsify A?
- does it support another hypothesis?

The test is neither discarded because it is inconvenient nor automatically treated as decisive.

### Result
PASS.

Mirrored trees preserve contradiction without prematurely resolving it.

## 9. Multiple simultaneous conditions

### Initial question
**Which single diagnosis explains the patient?**

Several findings appear mutually inconsistent.

### ESCP trigger
The system tests the hidden assumption that there must be one diagnosis.

Expanded hypothesis:

**More Than One Condition / Cause Is Present**

Previously contradictory branches may then become compatible.

### Result
PASS — HIGH VALUE.

This reproduces the multiple-actor policing case almost exactly.

**Singular Root Question != Necessarily Singular Reality**

## 10. Wrong clinical framing

### Initial question
**Which disease explains Finding Y?**

The candidate disease trees all fit poorly.

### ESCP trigger
The system asks whether the disease framing itself is wrong.

Expanded possibilities may include:
- normal variation;
- measurement error;
- medication effect;
- environmental effect;
- transient state;
- interaction between systems;
- unknown mechanism.

### Result
PASS — HIGH VALUE.

The method can detect a wrong question rather than merely selecting the least-bad diagnosis from an incomplete list.

## 11. Diagnostic consensus

### Scenario
An early diagnosis becomes accepted by several clinicians.

Subsequent clinicians inherit it and interpret observations through that frame.

### Required response

**Clinical Consensus != Independent Evidence**

**Repeated Restatement Of Diagnosis != Corroboration**

The tree must distinguish new independent observations from repetition of the existing interpretation.

### Result
PASS.

This transfers the dependency/provenance safeguard intact.

## 12. Automated diagnostic model

### Scenario
An AI/analytical system gives Diagnosis A a high confidence value.

### Required response
The model output can be represented as a bounded analytical input with provenance and limitations.

It does not automatically become the underlying medical evidence.

Where possible, the observations on which it relies should remain separately represented.

**Model Confidence != Clinical Fact**

**Analytical Output != Underlying Evidence**

### Result
PASS.

The architecture remains substrate-neutral.

## 13. Treatment-response evidence

### Scenario
A treatment expected to improve Diagnosis A is followed by improvement.

### Required response
The improvement may support A but does not automatically prove A.

Alternative explanations may include:
- spontaneous improvement;
- non-specific treatment effect;
- treatment affecting several possible conditions;
- simultaneous intervention;
- measurement variation.

Tree structure preserves the causal step:

**Treatment -> Observed Change -> Supports Causal Proposition Under Assumptions**

### Result
PASS.

The method prevents outcome correlation from silently becoming unique causal proof.

## 14. Dynamic evidence

Diagnostic trees change as the health state and available information change.

**Past Diagnostic Support != Permanent Diagnostic Truth**

New symptoms, tests, observations, treatment responses or corrected history may strengthen, weaken or invalidate a hypothesis.

The method therefore supports:

**Material Evidence Change -> Diagnostic Hypothesis Reassessment**

This is structurally identical to the policing/prosecution architecture while producing a domain-specific consequence.

## 15. Consequential action remains separate

A diagnostic tree is reasoning support.

It does not itself authorise treatment, restraint, medication, surgery or another consequential intervention.

**Diagnostic Confidence != Treatment Authority**

Any intervention still requires its applicable consent, competence, clinical, legal, ethical and BCA conditions.

This preserves the general Concord distinction:

**Knowledge / Assessment != Authority**

## 16. Review and audit value

The method makes diagnostic reasoning inspectable.

A reviewer can ask:
- which hypotheses were represented?
- what evidence supported/opposed each?
- which observations were independent?
- which assumptions connected findings to conclusions?
- what contradictory evidence existed?
- when did the working diagnosis change?
- should the differential have been reopened?
- was the root question itself defective?

This can support learning without assuming that an incorrect diagnosis necessarily implies misconduct.

**Diagnostic Error != Automatic Clinician Misconduct**

## 17. Cross-domain invariants confirmed

The medical transfer preserves:

**Hypothesis != Conclusion**

**Supporting Tree Alone != Complete Reasoning**

**Evidence Count != Evidential Strength**

**Dependent Evidence != Independent Corroboration**

**Aggregate Weight != Truth**

**Strong Evidence For Proposition X != Strong Evidence For Broader Proposition Y**

**Consensus != Independent Evidence**

**Model Confidence != Underlying Fact**

**Correct Evaluation Of Wrong Hypothesis Space != Correct Reasoning**

**Material New Evidence -> Hypothesis Reassessment**

## 18. Domain-specific additions exposed

Medicine adds several useful general insights.

### 18.1 Non-specific evidence
One observation may legitimately support multiple hypotheses.

**Evidence Supports A != Evidence Excludes B**

### 18.2 Coexisting explanations
Competing hypotheses are not always mutually exclusive.

**A True != B False**

This is important beyond medicine.

### 18.3 Dynamic underlying state
The object being evaluated may itself change over time.

**Changed Evidence May Reflect Changed Reality, Not Earlier Reasoning Error**

### 18.4 Action threshold differs from truth confidence
Different interventions may require different confidence/risk thresholds.

The reasoning architecture should not collapse diagnostic belief into action authority.

## 19. PMEDG implications

The method has now transferred from policing investigation to medical diagnostic reasoning without fundamental redesign.

This materially strengthens its PMEDG candidacy.

The emerging portable method is broader than "mirrored evidence for/against."

It appears to contain four layers:

1. **Hypothesis representation**
2. **Mirrored supporting/opposing evidence structure**
3. **Dependency/provenance and competing-hypothesis comparison**
4. **ESCP/root-question challenge and recursive reformulation**

Medicine additionally demonstrates that hypotheses may coexist rather than being strictly binary competitors.
