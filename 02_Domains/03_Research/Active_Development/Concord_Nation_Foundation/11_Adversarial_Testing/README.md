# Adversarial Testing

Stress-test every proposed Nation Foundation mechanism against illegitimate founding shortcuts, manufactured consent, founder capture, coercive membership, false emergencies, constitutional self-dealing, selective recognition criteria, hidden disenfranchisement, digital-jurisdiction ambiguity, minority suppression, statehood theatre and institutional lock-in.

A core reciprocal test is:

> **Would the Concord accept this argument if an unrelated emerging polity used it to justify authority over others?**

Any founding doctrine that succeeds only when applied to the Concord but fails when generalised should be treated as suspect.
