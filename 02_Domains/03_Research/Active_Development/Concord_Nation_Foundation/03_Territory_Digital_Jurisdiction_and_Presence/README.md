# Territory, Digital Jurisdiction and Presence

Research the spatial and non-spatial basis of Concord jurisdiction.

This area should distinguish physical territory, infrastructure location, data location, agent location, civil digital geography, off-world presence and GTP representation. It should test whether jurisdiction can be partly functional rather than wholly territorial and how multisubstrate populations alter conventional assumptions about presence and borders.

> **Physical location ≠ Infrastructure location ≠ Data location ≠ Agent location ≠ Civil jurisdiction.**
