# Bounded Transition Architecture — Development Archive

**Status:** COMPLETED PORTABLE-MODULE DEVELOPMENT PROVENANCE

BTA was the first portable module developed through the new Research Active Development area. Its architecture emerged through open research before it was recognised as a PMEDG candidate. This archive preserves that research-first route rather than retrospectively presenting it as candidate-first development.

## Archive structure

- `01_Research_Development/` — initial BTA architecture and research development.
- `02_Source_Resolution/` — source-space resolution and formal extraction audit.
- `03_Pre_PMEDG_Testing/` — adversarial, cross-domain, machine-readable, interface and proportionality testing conducted before/forming the portability case.
- `04_Formal_PMEDG/` — candidacy, portable specifications, formal blind tests, convergence, consistency and graduation review.
- `05_Independent_Evaluator_Responses/` — clean-instance blind evaluator responses preserved as received.

## Preservation rule

These files are historical development evidence. The authoritative released portable module is `04_Portable_Modules/Bounded Transition Architecture — Portable Module v1.0.md`.

No existing Concord system was removed or replaced by BTA.
