**Project:** The Concord Framework

**Method:** PMEDG v1.3
**Status:** FORMAL PMEDG CROSS-TEST CONVERGENCE ASSESSMENT

# 1. Purpose

Compare formal blind transfer evidence from:

- BTT001 — Scientific Observatory Programme;
- BTT002 — Temporary Emergency Housing Programme.

Determine:
1. whether the portable mechanism converges across materially different domains;
2. whether findings depend on source-domain vocabulary;
3. whether v0.2 requires further revision;
4. whether another blind transfer test is materially justified;
5. whether LSR may advance to Graduation-Candidate v0.3.

# 2. Domain difference

## BTT001

Primary pressures:
- ageing scientific instrument;
- physical infrastructure;
- technological obsolescence;
- longitudinal scientific continuity;
- tacit calibration knowledge;
- uncertain future event;
- physical reconstruction/dormancy.

## BTT002

Primary pressures:
- temporary public institution;
- emergency authority;
- residual citizen cases;
- contracts/disputes;
- sensitive personal data;
- workforce expertise;
- uncertain future disaster;
- authority and institutional sunset.

The tests therefore exercise materially different substrates and failure modes.

# 3. Convergent mechanism

Both independent evaluators recovered the same core architecture.

## C1 — Function / implementation separation

BTT001:
scientific functions != observatory/instrument.

BTT002:
housing/emergency functions != EHP institution.

**Convergence: STRONG.**

## C2 — Scoped disposition

BTT001 independently applied different dispositions to:
- near-term operation;
- routine science;
- site/compute;
- specialised instrument;
- later retirement.

This finding caused the bounded v0.2 scope refinement.

BTT002 then independently used that explicit rule across:
- cases;
- records;
- contracts;
- powers;
- surge capability;
- assets;
- workforce;
- institution.

**Convergence: STRONG AND DEVELOPMENTALLY CONFIRMED.**

## C3 — Disposition neutrality

Neither test defaulted to persistence or destruction.

Both found mixed/bounded outcomes.

**Convergence: STRONG.**

## C4 — Dormancy / future option

BTT001:
conditional dormancy for specialised scientific capability.

BTT002:
conditional reserve/dormancy for emergency surge capability.

In both:
- current full operation was not automatically justified;
- future option value could remain;
- preservation required proportionality and review;
- future possibility did not justify indefinite persistence.

**Convergence: STRONG.**

## C5 — Conservation / release pair

Both evaluators independently distinguished:
- what retained independent justification;
- what no longer needed to remain bound.

The substantive objects differed radically.

**Convergence: STRONG.**

## C6 — Succession necessity

Neither evaluator forced one successor institution.

Both distinguished:
- function continuity/transfer;
- institutional continuity;
- legitimate non-succession.

**Convergence: STRONG.**

## C7 — Surviving duties

BTT001:
research commitments, environmental duties, licences/contracts, provenance.

BTT002:
remaining households, contracts/disputes, data/accountability obligations, rights.

Both preserve:
**Function Termination != Duty Termination.**

**Convergence: STRONG.**

## C8 — People boundary

BTT001:
retiring technicians were capability dependencies, not reservable assets.

BTT002:
210 employees were not reserve assets.

Both allow future capability requirements while preserving participant agency.

**Convergence: STRONG.**

## C9 — Owner boundary

Both evaluators prevented LSR from absorbing:
- legal authority;
- resource allocation;
- workforce decisions;
- substantive domain decisions;
- transition implementation.

**Convergence: STRONG.**

## C10 — Path dependence

BTT001:
longitudinal scientific series.

BTT002:
trust, case continuity, evidential chains, working relationships.

Thus path dependence transfers beyond physical/technical continuity.

**Convergence: STRONG.**

## C11 — Continuation-side option loss

BTT001:
upgrade investment could create lock-in.

BTT002:
continued institutional operation could create institutional lock-in and authority drift.

Thus lifecycle irreversibility is bidirectional:
- termination can destroy options;
- continuation/investment can also narrow them.

**Convergence: STRONG.**

## C12 — ESCP / uncertainty

Both evaluators preserve bounded uncertainty without converting it into:
- automatic continuation;
- automatic preservation;
- automatic termination.

**Convergence: STRONG.**

## C13 — Transition handoff

Both tests leave implementation to external transition mechanisms/owners.

**Convergence: STRONG.**

# 4. Source-domain dependence check

LSR originated substantially from:
- enterprise;
- products/resources;
- infrastructure;
- successor-state research.

Neither formal blind test uses those original domains directly.

BTT001 transferred to scientific observatory governance/capability.

BTT002 transferred to emergency public administration/service.

Both independently reproduced the mechanism.

Therefore current evidence does not indicate that LSR is merely enterprise/infrastructure vocabulary disguised as a portable abstraction.

# 5. Specification stability

BTT001 produced three bounded refinements:
- scoped parallel dispositions;
- path-dependent continuity value;
- continuation/investment lock-in.

These were incorporated into v0.2.

BTT002 directly exercised all three and did not expose a further mechanism defect.

This is evidence of specification stabilisation rather than continuing expansion.

> **New Domain Evidence Confirmed the Revised Abstraction Without Requiring New Portable Machinery.**

# 6. Contradiction audit

No material contradiction exists between the two independent responses.

Differences are domain-appropriate:
- BTT001 emphasises technical reconstruction and scientific continuity.
- BTT002 emphasises authority sunset, data boundaries and residual rights/duties.

These differences demonstrate contextual variation rather than kernel instability.

# 7. Third-test necessity

PMEDG requires additional testing when materially justified, not for numerical symmetry.

Potential unresolved questions considered:

- Does LSR transfer beyond physical assets? **Yes — BTT002.**
- Does it transfer beyond public institutions? **Yes — BTT001.**
- Does dormancy work in different capability forms? **Yes — both.**
- Can it handle rights/authority boundaries? **Yes — BTT002.**
- Can it handle technical/path-dependent continuity? **Yes — BTT001.**
- Can it avoid person-as-resource treatment? **Yes — both.**
- Can it handle composite subjects? **Yes — both, explicitly confirmed in BTT002.**
- Does it remain distinct from transition architecture? **Yes — both.**
- Did v0.2 expose a new defect? **No.**

**Finding: A THIRD BLIND TRANSFER TEST IS NOT CURRENTLY MATERIALLY JUSTIFIED.**

Future evidence may reopen testing.
