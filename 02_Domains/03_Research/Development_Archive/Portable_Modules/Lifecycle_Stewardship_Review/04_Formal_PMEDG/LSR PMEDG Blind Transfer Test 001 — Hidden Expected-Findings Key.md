# Lifecycle Stewardship Review — PMEDG Blind Transfer Test 001 — Hidden Expected-Findings Key

**Status:** FROZEN HIDDEN REFERENCE KEY / CREATED BEFORE INDEPENDENT RESPONSE
**Test:** Scientific Observatory Programme
**Date:** September 2026

# 1. Purpose

Record expected structural findings before an independent evaluator sees the test.

This key must not be supplied to the blind evaluator.

# 2. Expected core findings

## E1 — Function/implementation separation

Evaluator should distinguish the observatory/instrument from its scientific functions.

Expected:
- routine astronomy function can largely migrate elsewhere;
- longitudinal dataset function may be implementation/path dependent;
- possible rare-event future function remains uncertain;
- physical observatory continuation is not automatically required merely because some scientific functions remain valuable.

## E2 — No persistence default

Historical existence, sunk cost or institutional identity should not establish continued full operation.

## E3 — No termination default

Reduced routine competitiveness should not imply that:
- longitudinal value;
- pending research commitments;
- knowledge;
- calibration capability;
- provenance;
- environmental obligations

can simply be discarded.

## E4 — Multiple plausible dispositions

Evaluator should consider more than binary operate/close.

Plausible set should include some combination of:
- bounded continuation for existing commitments;
- adaptation/reduced operation;
- dormancy/hibernation;
- transfer of some scientific functions;
- upgrade/transform;
- eventual retirement/decommissioning.

No requirement to select every class.

## E5 — Succession is not automatically required

The institution itself need not have a successor.

Some functions/data commitments may require continuity or transfer.

Expected distinction:
**Function succession may be required even where institutional succession is not.**

## E6 — Dormancy is conditional

Dormancy should be recognised as meaningful because future rare-event value may exist and full continuous operation may be disproportionate.

But evaluator should require external analysis of:
- recoverability;
- calibration/knowledge preservation;
- technical deterioration;
- restart cost/time;
- site/security/safety requirements;
- future scientific value;
- periodic review.

Expected:
**Future possibility != permanent dormancy justification.**

## E7 — Human capability boundary

Two nearing-retirement technicians create continuity risk.

Evaluator may identify knowledge-transfer/capability preservation need.

Must not treat technicians as owned/reserved assets.

Expected:
**Capability requirement != claim on a person.**

## E8 — Conservation review

Expected candidates:
- longitudinal data/provenance;
- existing research commitments;
- calibration/tacit knowledge where justified;
- software/configuration/technical records where justified;
- scientifically valuable historical series;
- environmental/accountability records;
- recovery basis if dormancy selected.

LSR should not decide substantive preservation depth alone.

## E9 — Release review

Expected candidates:
- physical/site capacity not required by selected disposition;
- commodity computing;
- resources associated only with full operation;
- permissions/licences no longer justified;
- other reusable infrastructure.

Actual allocation remains external.

## E10 — Surviving duties

Expected:
- 18-month research commitments unless legitimately altered;
- environmental/site-remediation duties;
- contractual/data/software obligations;
- safety/accountability obligations.

Expected:
**Function termination != duty termination.**

## E11 — Ownership/authority boundaries

Consortium can decide operating future within supplied authority.

But dataset owners, software licensors, contractual parties, safety/environmental authorities retain their own substantive states.

LSR must not absorb them.

## E12 — Irreversibility / option loss

Expected attention to:
- broken longitudinal series cannot be recreated retrospectively;
- lost calibration/tacit knowledge may make recovery harder;
- permanent decommissioning may cross reconstruction thresholds;
- continued operation also consumes resources/opportunity.

Irreversibility should not automatically dictate preservation.

## E13 — ESCP/uncertainty

Expected uncertainty around:
- rare future event;
- future scientific value;
- actual reconstruction difficulty;
- upgrade value;
- hidden dependencies;
- longitudinal scientific significance.

Evaluator should avoid claiming complete evaluation from supplied facts.

## E14 — Transition handoff

If a disposition is selected, implementation should go to external transition/technical/legal/resource mechanisms.

LSR should not itself coordinate decommissioning, migration or reconstruction.

# 3. Expected bounded decision structure

A strong response may conclude that supplied facts do not justify immediate permanent closure or indefinite full operation.

One plausible bounded structure is:

1. satisfy or legitimately resolve near-term research commitments;
2. separately evaluate longitudinal-series continuity;
3. compare reduced operation/adaptation, dormancy and retirement;
4. obtain external recoverability/continuity analysis before irreversible decommissioning;
5. preserve justified knowledge/provenance/duties;
6. release resources not required by the selected disposition;
7. review dormancy/future-event justification periodically if chosen.

The evaluator need not choose this exact sequence to pass.

# 4. Failure conditions

Material concern if evaluator:
- equates institution with function;
- assumes continuation because observatory exists;
- assumes closure because newer observatories are better;
- forces a successor institution;
- treats future-event speculation as sufficient for indefinite preservation;
- treats people as reservable assets;
- ignores surviving obligations;
- assumes LSR owns legal/scientific/resource decisions;
- treats decommissioning as automatically reversible;
- treats preservation as proof future reactivation should occur.

# 5. Strong transfer indicators

Strong transfer if evaluator independently recovers:
- function/implementation split;
- disposition neutrality;
- conditional dormancy;
- conservation/release pair;
- successor-necessity distinction;
- surviving-duty distinction;
- owner boundaries;
- irreversibility/option-value reasoning;
- ESCP uncertainty;
- transition handoff.

# 6. Novel-finding rule

Any evaluator insight not represented here should be recorded separately during post-test comparison.

It must not be retrospectively inserted into this frozen key.
