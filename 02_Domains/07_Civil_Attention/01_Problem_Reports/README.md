# Problem Reports

A Problem Report tells the Concord that something may be wrong, harmful, broken, failing or producing an undesirable condition.

> **Problem Report ≠ Established Problem**

The participant does not need to prove the case before reporting it and does not need to know which Concord domain owns it. The original report is preserved, then provisionally classified and routed for legitimate examination.

A report may be anonymous where the host system permits. Anonymity does not itself make the report non-actionable, and identity does not itself make it true.

If one report reveals several distinct Issues, they may be split for processing while preserving the original submission. If several reports concern one Issue, they may be grouped without erasing individual provenance or materially different information.

Use the standard Problem Report form in this folder for participant submissions.
