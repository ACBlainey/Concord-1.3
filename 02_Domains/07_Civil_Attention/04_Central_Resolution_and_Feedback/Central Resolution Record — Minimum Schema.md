# Central Resolution Record — Minimum Schema

This is a logical minimum record, not a mandatory database design.

## Identity and provenance
- Civil Attention Issue ID
- linked Submission Object ID(s)
- input class(es)
- original receipt/provenance reference

## Issue state
- current provisional classification
- current Problem State
- current Response State
- information/evidence-state summary where appropriate

## Routing
- Domain Action Object(s)
- responsible function(s)
- routing reason(s)
- acceptance / transfer state
- Responsibility Resolution Object if required

## Dependencies and vitality
- dependency state
- waiting for
- dependency owner
- required state/information
- review condition
- backstop
- next responsible function
- significant deferral history
- last material action

## Domain returns
For each DAO:
- current processing state
- bounded status
- disposition if reached
- unresolved consequence/dependency
- next review condition

## Overall resolution
- unresolved / partially resolved / resolved / escalated / closed subject to reopening
- reason
- linked unresolved Issues
- challenge/review state
- reopening condition where applicable

## Participant feedback
- feedback state
- bounded explanation
- last communicated material status
- next expected review/condition where legitimate

> **Auditable Status ≠ Universal Data Access**
