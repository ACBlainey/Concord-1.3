# Petitions

A Petition records collective concern, preference or a request for consideration or action.

> **Petition Support ≠ Problem Weight**

Support is a legitimate attention signal. It does not by itself prove the underlying claim, determine severity, manufacture priority or command resources.

Civil Attention preserves the petition, evaluates what Issue or Issues it concerns, and routes those Issues to legitimate domain owners. The petition's support and provenance remain visible without replacing evidence or substantive assessment.

Use the standard Petition form in this folder.
