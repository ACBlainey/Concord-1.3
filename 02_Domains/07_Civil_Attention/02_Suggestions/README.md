# Suggestions

A Suggestion proposes a possible improvement, solution or opportunity for the Concord or one of its domains.

A suggestion does not require popularity to have merit, and submitting a proposed solution does not grant authority to implement it.

The participant does not need to know the correct internal owner. Civil Attention preserves and routes the suggestion to the function or functions capable of legitimately evaluating it.

Suggestions may reveal underlying Problem Reports or several separate Issues. Those downstream objects should be linked without rewriting the original suggestion.

Use the standard Suggestion form in this folder.
