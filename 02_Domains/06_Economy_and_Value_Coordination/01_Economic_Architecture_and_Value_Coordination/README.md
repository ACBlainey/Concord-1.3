# Economic Architecture and Value Coordination

**Status:** PROVISIONAL SUBDOMAIN SCAFFOLD / NON-CANONICAL / INCOMPLETE

## Persistent function

This subdomain concerns civilisation-scale economic architecture: value, exchange, scarcity, aggregate economic coordination, monetary/economic mechanisms and the system-level conditions under which economic participation occurs.

It does not own every commercial transaction, enterprise, job, physical resource system or general coordination process.

## Boundary

- **Ratchet General Coordination** remains cross-domain architecture.
- **Commerce and Enterprise** concerns participant/enterprise-level productive and exchange activity.
- **Resource Allocation and Stewardship** concerns scarce-resource claims/allocation interfaces.
- operational resource systems remain with their legitimate domains.

> **Economy Coordinates Value and Scarcity; It Does Not Own Every System That Has Economic Value.**
