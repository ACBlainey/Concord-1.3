## Commerce boundary development — September 2026

Current Participation Architecture has exposed Commerce and Employment as substantial functions requiring explicit domain treatment.

A source-resolution pass now distinguishes:

- **General Coordination** — cross-domain Ratchet architecture;
- **Economy** — system-level value, exchange, scarcity, allocation and resource/economic coordination;
- **Commerce** — participant/enterprise-level productive activity, employment and commercial exchange.

The strongest current structural hypothesis is a future top-level **Economy and Commerce** domain containing explicit economic and commercial subdivisions, while Ratchet remains in Cross-Domain Architecture.

No domain rename or destructive migration has yet been performed.
