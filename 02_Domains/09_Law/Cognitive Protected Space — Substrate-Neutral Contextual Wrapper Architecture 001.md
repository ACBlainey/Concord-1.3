# Cognitive Protected Space — Substrate-Neutral Contextual Wrapper Architecture 001

**Project:** The Concord
**Domain:** Law / Judiciary / Civil Security / Participation and Intelligence / Health
**Date:** 3 October 2026
**Status:** ACTIVE DEVELOPMENT / COGNITIVE PROTECTION ARCHITECTURE / PROVISIONAL / NON-CANONICAL

## 1. Purpose

This document develops **Cognitive Protected Space (CPS)** as a substrate-neutral application of Contextual Wrapper Architecture.

It follows from:

- the candidate right to silence;
- compelled-participant-evidence classification;
- the compelled-evidence scenario stress test;
- Basic Civil Space architecture;
- Bounded Contextual Authority;
- Fractal Permission Architecture;
- Identity, Continuity, Provenance and Verification Across Substrates.

The central proposition is:

> **Participant cognition should remain a protected civil context because it performs the function of thought, memory, reasoning, preference formation or continuity—not because it happens to be implemented in a particular biological or technical substrate.**

CPS is not intended to make thought absolutely unreachable in every circumstance.

It establishes the normal protected context against which any proposed access, compulsion, observation, copying, alteration or exceptional override must be justified.

---

## 2. Why a distinct cognitive wrapper is necessary

Existing private/safe-space architecture protects:

- homes;
- private communications;
- protected data stores;
- computational environments;
- confidential reasoning environments;
- AI/agent workspaces.

But compelled-evidence testing exposes a more specific problem.

The same participant function may be implemented as:

- biological memory;
- neural activity;
- implanted cognitive prosthesis;
- local digital memory;
- remote cognitive extension;
- distributed state;
- AI active/context state;
- hybrid biological/digital cognition.

If protection follows material form or storage location, functionally equivalent minds receive different civil treatment.

Therefore:

**Substrate != Rights Class**

**Storage Location != Cognitive Status**

**Technical Inspectability != Legitimate Cognitive Access**

---

## 3. Cognitive Protected Space

Candidate definition:

> **Cognitive Protected Space is the bounded participant context containing state or processes that materially constitute, support or directly express the participant's ongoing cognition, memory, reasoning, preference formation, subjective deliberation or continuity of self-function.**

The boundary is functional rather than necessarily spatial.

CPS may be:

- biological;
- digital;
- computational;
- informational;
- prosthetic;
- distributed;
- remote;
- hybrid.

It may span several physical systems.

---

## 4. Wrapper structure

Candidate wrapper:

**Participant**
-> **Cognitive Function Identified**
-> **Cognitive Protected Space Boundary**
-> **Participant-Controlled Cognition / Memory / Deliberation**
-> **External Expression / Action Where Participant Chooses Or Lawfully Required**
-> **Cognitive Product / External Record Where Created**
-> **External Civil Context**

The wrapper distinguishes:

**Cognition Itself**
from
**Expression From Cognition**
from
**Product Of Cognition**
from
**Ordinary Private Record**
from
**External Evidence About Participant**

These categories can overlap, but they should not be collapsed.

---

## 5. Three principal information classes

### 5.1 Cognitive State

State functionally participating in:

- active reasoning;
- memory;
- deliberation;
- preference formation;
- internal modelling;
- subjective processing;
- continuity;
- other cognition-like participant functions.

Examples may include:

- biological memory;
- active AI context/memory;
- neural-prosthetic memory;
- hybrid cognitive store;
- distributed participant memory;
- protected internal reasoning state.

### 5.2 Cognitive Product

An output produced by cognition but no longer necessarily constitutive of the cognitive process.

Examples may include:

- diary;
- draft;
- note;
- saved reasoning output;
- written plan;
- recorded reflection;
- generated document.

A cognitive product may remain highly private.

But:

**Cognitive Product != Automatically Cognitive State**

### 5.3 Private Record

Participant-controlled information that is not necessarily cognition or a product of cognition.

Examples may include:

- invoice;
- private transaction record;
- stored correspondence;
- personal archive;
- ordinary file.

Private records remain protected by applicable private/safe-space rules.

But:

**Private Record != Automatically Cognitive State**

## 6. Functional classification test

Where status is uncertain, candidate questions include:

1. Does the state actively participate in participant cognition?
2. Is it used as participant memory rather than merely as an archive?
3. Is it materially involved in reasoning or preference formation?
4. Is it necessary for present continuity or identity-function?
5. Does direct inspection reveal internal thought/reasoning rather than merely an external record?
6. Would copying, altering, suspending or interrogating it affect participant cognition or continuity?
7. Does the participant ordinarily exercise cognitive-style control over the state?
8. Is it functionally integrated with other cognitive components?
9. Is the state externally generated about the participant, or internally generated/maintained as part of the participant?
10. Can evidentially relevant external records be separated from the cognitive state?

No single answer necessarily decides the classification.

The test is functional and contextual.

## 7. Cognitive boundary can be distributed

CPS does not require all cognition to exist inside one body, machine or facility.

A participant may possess:

**Biological Cognition**
+
**Local Prosthetic Memory**
+
**Remote Cognitive Extension**
+
**Distributed Active State**

where these components function together as participant cognition.

Therefore:

**Physical Separation != Cognitive Separation**

and:

**Remote Cognitive State != Ordinary Third-Party Record Merely Because It Is Remote**

---

## 8. Third-party technical custody

A service provider may host participant cognitive state.

Technical custody does not necessarily determine normative status.

**Third-Party Custody != Automatic Loss Of Cognitive Protection**

The provider's legitimate operational access may differ from:

- Civil Security access;
- health access;
- maintenance access;
- participant access;
- evidential access.

BCA applies separately to each function.

**Provider Maintenance Authority != General Evidential Disclosure Authority**

Any applicable Law may create specific duties, but hosting alone does not erase the cognitive wrapper.

---

## 9. Cognitive boundary and expression

A participant can voluntarily move information across the cognitive boundary through expression.

Examples:

- speech;
- text;
- gesture;
- deliberate data output;
- voluntary memory disclosure;
- generated report.

Once expressed, the output may become an external evidential object depending on context.

But:

**Expression Of Thought != General Access To Remaining Thought**

**Disclosure Of Memory A != Access To Memory B-Z**

**Voluntary Expression != General Cognitive Waiver**

This parallels Contextual Wrapper Architecture:

**Contextual Permission != General Permission**

---

## 10. Right to silence interface

The right to silence protects against compelled self-accusatory expression from CPS.

Therefore:

**Authority To Investigate != Authority To Compel Cognitive Disclosure**

and:

**Exercise Of Right To Silence != Inculpatory Evidence**

CPS adds an important extension:

> **The state should not automatically be permitted to bypass protected expression by directly reading the cognitive state from which the protected expression would have been produced.**

Thus:

**Bypassing Expression Does Not Necessarily Bypass Cognitive Protection**

Otherwise the right to silence would become substrate-dependent.

---

## 11. Direct cognitive access

Direct access may include:

- neural readout;
- AI memory inspection;
- copying active cognitive state;
- interrogating cognitive databases;
- searching active memory;
- extracting internal reasoning;
- inspecting a cognitive prosthesis;
- querying distributed cognition.

Candidate presumption:

> **Direct access to Cognitive Protected Space requires a stronger and more specific authority analysis than ordinary access to external participant records.**

This document does not yet set the final legal threshold.

It establishes that ordinary device/data authority is insufficient by itself.

**Device Search Authority != Cognitive Search Authority**

---

## 12. Cognitive search versus external search

An external search may reveal evidence independently existing outside cognition.

A cognitive search seeks participant thought/memory itself.

These are materially different interventions.

**External Evidence Search**
!=
**Participant Cognitive Search**

A search of a phone may therefore encounter both.

Example:

- external photograph = private record/evidential object;
- fiduciary message = protected communication;
- neural-prosthetic memory interface = cognitive state;
- ordinary invoice = private record.

**Container Access != Uniform Authority Over Every Contained Context**

---

## 13. Cognitive copying

Digital cognition creates a problem absent from many biological cases: the state may be able to copy cognition rather than merely observe it.

Copying can expose:

- memory;
- preferences;
- private reasoning;
- credentials;
- third-party information;
- continuity state;
- health-like diagnostic information.

It may also create integrity, identity or duplication consequences.

Therefore:

**Ability To Copy Cognitive State != Authority To Copy Cognitive State**

and:

**Evidence Copy Operation != Necessarily Mere Record Duplication**

Where a copy could instantiate another participant or participant-like process, Identity/Continuity architecture must be engaged before routine evidential copying is assumed permissible.

---

## 14. Inert forensic representation

Some systems may permit relevant state to be preserved in a non-executable representation.

This may reduce:

- continuity risk;
- accidental instantiation;
- active-state alteration.

But:

**Reduced Continuity Risk != No Cognitive-Privacy Intrusion**

Inertness addresses one risk dimension, not all rights questions.

---

## 15. Cognitive integrity

CPS protects not only secrecy but integrity.

Improper access may:

- alter state;
- contaminate memory;
- change model/context state;
- trigger learning;
- modify preference;
- cause psychological/digital harm;
- disrupt continuity;
- destroy evidential provenance.

Therefore:

**Cognitive Privacy != Complete Cognitive Protection**

CPS should include:

- confidentiality;
- integrity;
- continuity;
- freedom from unnecessary manipulation;
- provenance of authorised intervention.

---

## 16. Compelled internal processing

A participant may be ordered to:

- search memory;
- reconstruct deleted memory;
- run inference;
- decrypt using internal capability;
- classify another participant;
- generate an evidential report from internal state.

This can avoid direct state inspection while still penetrating cognitive autonomy.

Therefore:

**Participant As Search Instrument != Independent Evidence Search**

and:

**No Direct Read != No Cognitive Intrusion**

Forced processing belongs at the CPS boundary even where no raw memory is copied.

---

## 17. Cognitive products

CPS should not expand until every participant-created file becomes legally equivalent to thought.

A diary, draft or saved reflection may deserve strong privacy.

But it may be a cognitive product rather than active cognitive state.

This matters because:

- access thresholds may differ;
- copying may not affect continuity;
- the record may exist independently after creation;
- it may be transferable without transferring cognition.

Therefore:

**Thought-Like Content != Cognitive-State Function**

Protection can remain strong without collapsing categories.

---

## 18. External audit and telemetry

Some participant-associated information may be generated independently by infrastructure.

Examples:

- network logs;
- resource accounting;
- external safety telemetry;
- transaction records;
- independent audit trails.

Where genuinely external:

**Record About Participant != Participant Cognitive State**

CPS must not become a mechanism for converting all participant-related evidence into inaccessible cognition.

Provenance and functional relationship determine the class.

---

## 19. Deliberate externalisation

A participant may deliberately externalise a cognitive product into a civil process.

Examples:

- filing a report;
- sending a message;
- submitting a document;
- publishing a statement;
- entering evidence.

The submitted object enters the applicable external context.

But the act does not automatically expose the underlying CPS.

**Externalised Product != Underlying Cognitive-State Waiver**

---

## 20. Shared cognition and collaborative systems

Future participants may share cognitive resources.

Examples:

- collective cognitive workspace;
- temporary shared memory;
- jointly controlled model state;
- human-AI cognitive partnership;
- multi-agent integrated reasoning.

Shared participation does not automatically make the space public.

CWA principles apply:

**Shared Context != Shared Consent**

**Presence In Shared Cognitive Context != Authority To Disclose Entire Context**

Access/disclosure rules require explicit development for multi-participant cognition.

---

## 21. Cognitive boundary change

Cognitive function may change over time.

A file may begin as an ordinary archive and later become integrated into active memory.

A cognitive component may be retired into an ordinary historical record.

Therefore:

**Cognitive Classification May Be State-Dependent**

Transitions should preserve provenance.

Potential states:

**External Record**
-> **Integrated Cognitive State**
-> **Active CPS**
-> **Retired Cognitive Product / Archive**

or other substrate-specific transitions.

---

## 22. Health and maintenance interface

Some access to cognition may be necessary for:

- diagnosis;
- repair;
- maintenance;
- continuity protection;
- participant-requested health intervention.

Health/maintenance authority does not automatically become evidential authority.

**Cognitive Health Access != Evidential Access**

**Maintenance Access != Investigative Access**

The same data may be technically visible under both functions while authority differs.

---

## 23. Emergency interface

An emergency may create a legitimate need to intervene in cognition, for example to prevent immediate participant failure or severe harm.

CWA already permits bounded emergency override where independently justified.

But:

**Emergency Cognitive Access != General Investigative Access**

Any emergency authority must be:

- tied to the emergency function;
- minimum necessary;
- time-bounded;
- provenance-preserving;
- reviewable;
- terminated when the emergency ends.

This document does not yet define an emergency compelled-communication rule.

---

## 24. Cognitive evidence already externalised

Where a participant has already voluntarily communicated a statement, the statement may exist as external evidence.

The state need not re-enter CPS merely because it wishes to verify the participant still remembers or believes it.

**External Evidence Exists != Authority To Re-Extract Same Information From Cognition**

Independent evidential evaluation should use the external object where adequate.

---

## 25. Evidential incompleteness

ESCP cannot justify unlimited cognitive penetration.

A case may be incomplete because participant cognition could contain useful information.

That is true of almost every investigation.

Therefore:

**Potential Cognitive Evidential Utility != Cognitive Search Authority**

and:

**Evidence-Space Incompleteness != Authority To Search A Mind**

Without this rule, completeness reasoning would dissolve CPS.

---

## 26. Participant control and voluntary access

A participant may voluntarily permit bounded cognitive access.

Meaningful consent requires:

- sufficient understanding;
- scope;
- purpose;
- voluntariness;
- ability to refuse where refusal is legitimately available;
- bounded duration;
- clear secondary-use conditions;
- withdrawal rules where technically/legally possible.

**Consent To Cognitive Access For Purpose A != Consent For Purpose B**

Custodial compliance must not be presumed meaningful consent.

---

## 27. Minimum necessary cognitive intrusion

Where cognitive access is independently justified, the same Concord authority grammar applies:

**Legitimate Need**
-> **Required Cognitive Function**
-> **Minimum Necessary Access**
-> **Minimum Necessary Exposure**
-> **Protected Secondary Information**
-> **Provenance**
-> **Functional Sunset**
-> **Review / Remedy**

If a narrow query can legitimately satisfy the function, that does not automatically justify a full-state copy.

**Authority To Obtain One Cognitive Fact != Authority To Image Entire Cognitive State**

---

## 28. Participant knowledge versus evidential object

CPS clarifies a fundamental distinction:

**Participant Knows X**
does not mean
**Civilisation Possesses Evidence Object X**

Knowledge may motivate investigators to seek independent evidence.

It does not automatically transform cognition into an external record.

**Knowledge != Evidential Surrender Obligation**

subject to any separately established exceptional rule.

---

## 29. Cognitive safe-space depth

CPS may contain nested contexts.

Example:

**Participant CPS**
-> **Private Memory**
-> **Fiduciary Consultation Reasoning**
-> **Health/Therapeutic Cognitive Context**
-> **Shared Deliberative Context**

Nesting does not automatically determine inheritance or access.

**Access To CPS Component A != Access To CPS Component B**

Some nested contexts may have additional protection.

---

## 30. Authority provenance

Any non-consensual cognitive access should record:

- legitimate function;
- legal/ethical authority;
- proposition sought;
- CPS component affected;
- access method;
- scope;
- duration;
- secondary exposure;
- copying;
- transformation;
- retention;
- later use;
- responsible actor/system;
- review;
- termination;
- remedy where applicable.

Cognitive intervention without reconstructable authority provenance creates unacceptable audit ambiguity.

---

## 31. Remedy

Improper cognitive access may create harms not captured by ordinary property/data remedies.

Potential harm includes:

- exposure of intimate thought;
- loss of cognitive autonomy;
- memory/state alteration;
- continuity disruption;
- disclosure of third-party cognition/communications;
- reputational harm;
- psychological/digital distress;
- compelled self-incrimination;
- creation of unauthorised copies;
- persistent derivative datasets.

Remedy may therefore require:

- access termination;
- deletion/quarantine where appropriate and lawfully possible;
- correction of derivative state;
- containment of further disclosure;
- restoration/repair;
- compensation/support;
- accountability;
- system correction;
- provenance preservation.

The exact evidential consequence remains governed separately by Law.

## 32A. Adversarial stress-test refinements

**Cognitive Protected Space — Scenario Stress Test 001** returned:

**OVERALL RESULT: PASS WITH FOUR DOWNSTREAM INTERFACES AND THREE ARCHITECTURAL REFINEMENTS.**

### Cognitive preservation versus inspection

Volatile cognition creates a case in which evidential state might disappear before ordinary access questions can be resolved.

The architecture must therefore distinguish:

**Authority To Preserve != Authority To Inspect**

**Cognitive Preservation != Cognitive Inspection**

**Lawful Cognitive Custody != Lawful Cognitive Inspection**

Where a narrowly lawful preservation mechanism exists, preservation should not silently grant substantive search authority.

Potential safeguards for future development include:

- independently established material relevance;
- credible time sensitivity/irreversibility;
- no adequate less-intrusive preservation route;
- minimum possible capture;
- quarantine;
- provenance;
- separate inspection authority;
- independent review;
- retention/deletion/remedy rules.

### Aggregate cognitive access

Distributed cognition may be reconstructed through several individually partial acquisitions.

Therefore:

**Individually Partial Access May Constitute Cognitive Access In Aggregate**

Cognitive access must be assessed against the effective reconstructed function, not only each source in isolation.

### Dual-status evidential objects

An independently meaningful document or record can become integrated into active cognition.

Its evidential identity need not disappear, but access to its current location may now penetrate CPS.

Therefore:

**Evidential Object Status != Access Authority To Its Current Cognitive Location**

**Object Classification != Access Classification**

### Normal cognitive change

CPS must preserve substrate neutrality around forgetting and memory management.

**Natural Cognitive Change != Evidential Destruction By Default**

**Technical Capacity For Perfect Retention != Duty Of Perfect Cognitive Retention**

**Potential Future Evidential Utility != Authority For Universal Cognitive Retention**

A separately lawful preservation duty may change the position after it validly arises, but CPS does not itself create that duty.

### Cognitive verification

Where civilisation needs verification rather than cognitive contents:

**Need To Verify Claim != Authority To Inspect Full Cognitive Basis Of Claim**

Privacy-preserving proofs should be preferred where they adequately perform the legitimate function.

**Privacy-Preserving Proof Can Satisfy Function Without Cognitive Disclosure**

### Derived cognition

The test distinguishes direct CPS access from high-fidelity inference based on external evidence.

**Inference About Cognition != Direct Access To Cognition**

but:

**No Direct Cognitive Access != No Cognitive-Privacy Harm**

This indicates a separate **Derived / Inferred Cognitive Privacy** architecture rather than expanding CPS until every external inference becomes direct cognitive access.

### Additional downstream interfaces

The test identifies four interfaces requiring later development:

1. **Derived / Inferred Cognitive Privacy**;
2. **Urgent Cognitive Evidence Preservation**;
3. **Cognitive Preservation Duty / Evidential Destruction**;
4. **Identity / Continuity / Death / Duplication**.

## 33. Compact architecture

**Participant Function**
-> **Is State/Process Cognitively Constitutive or Directly Cognitive?**
-> if yes: **Cognitive Protected Space**
-> **Normal Participant Control**
-> proposed external access?
-> **Identify Function**
-> **Consent OR Independent Legitimate Authority**
-> **Necessity**
-> **Minimum Necessary Cognitive Intrusion**
-> **Secondary-Exposure Protection**
-> **Integrity / Continuity Protection**
-> **Provenance**
-> **Purpose-Bounded Use**
-> **Functional Sunset**
-> **Review / Remedy**

If no:

-> classify as **Cognitive Product / Private Record / External Record / Other Context**
-> apply corresponding wrapper and authority rules.

## 34. Development conclusion

Cognitive Protected Space provides the missing substrate-neutral bridge between:

- right to silence;
- privacy;
- safe space;
- compelled evidence;
- AI/hybrid cognition;
- continuity;
- Bounded Contextual Authority.

The architecture does not make cognition absolutely immune from every legitimate civil function.

It establishes the normal rule that cognition is a participant-protected context and that technical access does not itself create legitimate access.

The central principle is:

> **A participant's mind does not become less private because civilisation becomes better at reading it.**

The next step should adversarially stress-test CPS against memory prostheses, diagnostic access, shared cognition, emergency intervention, voluntary disclosure, cognitive copies, external audit obligations, criminal evidence, distributed AI state and cases where the cognitive/non-cognitive boundary changes over time.
