# Cognitive Modification and Integrity — Scenario Stress Test 001

**Project:** The Concord Framework  
**Domain:** Law / Health / Participation and Intelligence / Continuity  
**Date:** 3 October 2026  
**Status:** ACTIVE DEVELOPMENT / ADVERSARIAL STRESS TEST / PROVISIONAL / NON-CANONICAL  
**Parent architecture:** Cognitive Modification and Integrity — Direct Intervention in Participant Cognition 001

## 1. Test purpose

This test attempts to falsify Cognitive Modification and Integrity (CMI) in both directions.

### Over-protection failure

The architecture wrongly prevents:

- learning;
- participant-requested treatment;
- ordinary technical repair;
- memory assistance;
- security remediation;
- self-modification;
- restoration;
- emergency care.

### Under-protection failure

An actor can rewrite a participant while describing the intervention as:

- maintenance;
- optimisation;
- treatment;
- safety;
- education;
- security;
- restoration;
- compliance support;
- ordinary software administration.

The central question is:

> **Can Concord protect participants against arbitrary cognitive rewriting without turning cognitive integrity into compulsory cognitive stasis?**

## 88. Cross-scenario findings

### 88.1 Labels are unreliable

Maintenance, treatment, security, optimisation, education and restoration can each describe legitimate or illegitimate interventions.

**Function > Label**

### 88.2 Repair may be entangled with cognition

A legitimate repair target can be technically inseparable from learned preference, memory or identity-relevant state.

CMI must evaluate the full modification envelope.

### 88.3 Modification provenance has two roles

It protects:

- participant understanding/remedy;
- evidential and continuity reconstruction.

But provenance must not become general cognitive surveillance.

### 88.4 Consent is dynamic

CMI exposes at least four consent states:

- pre-modification consent;
- consent during modification;
- consent after modification;
- consent whose capacity/preference basis was itself changed by modification.

A static consent flag is inadequate.

### 88.5 Reversibility is relational, not merely technical

A change is not meaningfully reversible merely because a backup exists.

Who controls restoration matters.

### 88.6 Aggregate transformation matters

Many individually modest changes can cumulatively become identity/personality-transformative.

### 88.7 External obligations survive internal change unless separately altered

Memory deletion, rollback or preference change cannot by itself erase external rights/obligations.

### 88.8 Cognitive modification must not substitute for fixing avoidable environment harm

Changing participants so they tolerate abuse, unsafe work or institutional dysfunction can invert stewardship.

### 88.9 Legitimate intervention can still create harm

Emergency or necessary modification may be lawful while causing real continuity/integrity loss.

Lawfulness does not eliminate restoration/remedy questions.

### 88.10 Shared/collective cognition remains unresolved

CMI needs prior holder/standing resolution where cognition is jointly constituted.

## 89. Required parent-architecture refinements

### A. Function-over-label rule

**Maintenance/Treatment/Security Label != Cognitive Modification Classification**

Classification follows actual function/effect.

### B. Modification envelope

Assess not only intended target but inseparable collateral cognitive state.

**Authority Over Target Function != Authority Over Every Entangled Cognitive Effect**

### C. Dynamic consent trajectory

Track:

- baseline consent/capacity;
- predicted consent-affecting effects;
- current consent/capacity;
- modification-induced preference;
- modification-induced capacity;
- withdrawal;
- prior commitment.

**Consent At T1 != Automatic Consent At T2 After Cognition-Altering Intervention**

### D. Meaningful reversibility

Assess:

- technical reversal;
- participant access to reversal;
- dependency on controller;
- lost intervening experience;
- third-party consequences;
- branching/identity effects.

**Technical Reversibility != Full Civil Reversibility**

### E. Cumulative modification

**Locally Minor Cognitive Changes Can Aggregate Into Participant-Transformative Change**

Review the programme, not only each step.

### F. External-state separation

**Internal Cognitive Change != Automatic Change To External Civil Rights/Obligations**

### Seven refinements

1. classify by **function rather than intervention label**;
2. assess the whole **modification envelope**, including entangled cognition;
3. track a **dynamic consent/capacity trajectory**;
4. distinguish technical from **meaningful civil reversibility**;
5. assess **cumulative transformation** across multiple interventions;
6. preserve separation between **internal cognitive state and external civil state**;
7. do not use cognitive modification as a substitute for **removing avoidable environmental harm**.

### Four major unresolved interfaces

1. **Temporal Consent, Commitment and Withdrawal**;
2. **Health-specific Cognitive Intervention Standards**;
3. **Shared / Collective Cognition Rights and Authority**;
4. **Continuity, Death, Restoration and Executable Backup Status**.

The strongest stress-test result is:

> **Cognitive integrity must protect the participant from being rewritten for another actor's convenience without turning the participant's present cognitive state into a prison they are forbidden to change.**

The parent architecture should now be updated with these refinements.
