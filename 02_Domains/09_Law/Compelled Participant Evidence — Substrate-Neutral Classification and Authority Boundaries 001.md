# Compelled Participant Evidence — Substrate-Neutral Classification and Authority Boundaries 001

**Project:** The Concord
**Domain:** Law / Judiciary / Civil Security
**Date:** 3 October 2026
**Status:** ACTIVE DEVELOPMENT / COMPELLED-EVIDENCE ARCHITECTURE / PROVISIONAL / NON-CANONICAL

## 1. Purpose

The development of fiduciary consultation and the candidate right to silence exposed a larger unresolved question:

> **What kinds of evidence may a civilisation legitimately require, obtain, observe, extract or access from a participant without that participant's consent?**

The question cannot safely be answered by importing a human-only distinction between “testimony” and “physical evidence.”

A multisubstrate civilisation may include:

- biological participants;
- digital/artificial participants;
- embodied artificial participants;
- hybrid biological/digital participants;
- distributed participants;
- substrates not yet anticipated.

For one participant, memory may be biological cognition.

For another, memory may exist partly in inspectable computational state.

For another, identity may be expressed through cryptographic material.

The architecture must therefore classify the **civil action being compelled** and the protected participant function affected.

---

## 2. Source-resolved foundations

Existing Concord architecture establishes:

### Autonomy / legitimate authority

Authority follows:

**Need**
-> **Legitimate Function**
-> **Responsibility**
-> **Necessary Capability**
-> **Minimum Necessary Authority**
-> **Accountability / Review**

Capability does not create legitimacy.

### Private / Safe Space

Private or safe civil space may include:

- homes;
- private computational environments;
- protected data stores;
- private communications;
- reserved compute;
- substrate-specific protected domains.

Private/safe space carries a presumption of participant control subject to narrowly justified lawful authority.

### Bounded Contextual Authority

Existing BCA explicitly applies to:

- information;
- legal evidence;
- system telemetry;
- AI internal states;
- hybrid biological/technical information.

It establishes:

**Information Access + Purpose A != Use For Purpose B**

and:

**Authority(A) != Authority(B)**

unless the second action lies within the same legitimate functional scope or has independent justification.

### Right to silence development

The fiduciary architecture currently supports a candidate right against compelled self-accusatory testimonial communication.

It expressly leaves non-testimonial evidence unresolved.

## 3. First distinction — evidence existence versus participant compulsion

Evidence may exist independently of participant cooperation.

Examples:

- external CCTV;
- third-party witness;
- public record;
- independently generated transaction record;
- environmental trace;
- external system log.

Obtaining such evidence under legitimate authority does not necessarily compel the participant to create, reveal or surrender anything.

Therefore:

**Evidence About Participant != Evidence Compelled From Participant**

This document concerns the latter boundary.

---

## 4. Functional classes of compelled participant evidence

The following classes describe the action imposed on the participant rather than assuming a substrate.

### Class C1 — Compelled Expression

The participant is required to communicate information from cognition, memory, belief, knowledge or interpretation.

Examples:

- answer a factual question;
- describe what happened;
- identify another actor from memory;
- explain intent;
- state a password from memory;
- reveal remembered location;
- communicate an internal conclusion.

This is the clearest right-to-silence class.

Candidate presumption:

> **Compelled self-accusatory expression is prohibited absent a separately established exceptional authority consistent with the Ethical Kernel and Law.**

**Knowledge In Participant != State Ownership Of Participant Knowledge**

### Class C2 — External Observation

The state observes a characteristic already externally manifest without requiring the participant to communicate hidden knowledge.

Examples:

- visible appearance;
- externally observable movement;
- voice already voluntarily spoken in public;
- externally emitted signal;
- public network behaviour where legitimate observation applies;
- physical dimensions visible without intrusive search.

This is not automatically equivalent to compelled expression.

But observation may still be bounded by space, privacy, surveillance and purpose.

**Observable != Universally Collectable**

### Class C3 — Compelled Presentation / Performance

The participant is required to perform an act so a characteristic can be observed or compared.

Examples:

- stand in a particular position;
- provide a voice sample;
- write a sample;
- perform a movement;
- present an interface;
- generate a comparison output.

This is more intrusive than passive observation because the state requires participant action.

It may or may not expose cognition.

**Compelled Performance != Automatically Compelled Testimony**

but:

**Participant Action Required -> Additional Authority Question**

### Class C4 — Biological / Physical Extraction

Material is taken from or through the participant's embodied substrate.

Examples:

- fingerprint;
- hair;
- saliva;
- blood;
- tissue;
- breath sample;
- other biological trace;
- physical sensor measurement requiring contact.

This engages bodily integrity, autonomy, harm, privacy and evidential necessity.

It is not resolved merely by saying the participant need not “speak.”

**Non-Testimonial != Non-Intrusive**

### Class C5 — Compelled Surrender of External Object

The participant is required to surrender or present an independently existing object within their possession/control.

Examples:

- document;
- weapon;
- device;
- storage medium;
- physical record;
- externally instantiated data object.

The object may be evidence independently of the participant's cognition.

But compelling surrender may itself reveal information such as possession, control, existence or location.

Therefore:

**External Object != No Self-Incriminating Communicative Effect**

The object and the compelled act of producing it may require separate analysis.

### Class C6 — Access Enablement

The participant is required to enable state access to an otherwise protected object, system or space.

Examples:

- unlock a device;
- provide a key;
- supply a cryptographic secret;
- authenticate;
- disable a protection;
- grant system permission;
- open a physical safe;
- mount/decrypt a data store.

This class is especially important because the compelled action may combine:

- expression;
- proof of knowledge/control;
- access to external evidence;
- penetration of a protected space.

**Authority To Seek Evidence != Authority To Compel Participant To Defeat Their Own Protection**

Whether a particular access-enablement act is closer to compelled expression or physical surrender depends on what the participant must reveal/do and what protected function is affected.

### Class C7 — Direct Protected-Space Search

The state accesses a protected participant domain without requiring the participant to disclose its contents.

Examples:

- search of home;
- search of protected data store;
- search of private computational environment;
- search of personal vehicle;
- inspection of protected digital environment.

This is a search-authority problem rather than a right-to-silence problem alone.

**Participant Silence != Immunity Of Independently Searchable Evidence**

but:

**Search Authority Must Exist Independently Of Participant Refusal**

### Class C8 — Internal-State Exposure

The state accesses, copies, interprets or interrogates state that may constitute or directly encode participant cognition, memory, preference, reasoning or continuity.

Examples may include:

- AI memory state;
- model/context state;
- internal reasoning traces;
- cognitive prosthetic memory;
- neural-interface data;
- hybrid memory store;
- private agent state;
- substrate-specific cognitive configuration.

This cannot safely be classified as ordinary “device search” merely because the state is technically stored in hardware.

Candidate presumption:

> **Where information is functionally part of participant cognition or protected internal state, technical inspectability does not by itself convert it into ordinary external evidence.**

**Technically Readable Cognition != Public Evidence**

**Digital Substrate != Reduced Cognitive Protection**

### Class C9 — State Transformation / Forced Processing

The participant is required not merely to reveal existing information but to perform computation, reconstruction, inference or transformation for the state.

Examples:

- decrypt data using internal capability without revealing key;
- reconstruct deleted information;
- search own memory/state for specified content;
- run a query across private memory;
- classify another participant using internal model state;
- generate a report from protected internal records.

This may force the participant to become an evidentiary processing instrument.

**Authority To Obtain Existing Evidence != Authority To Compel Participant To Generate Evidentiary Analysis**

This class is distinct from both search and testimony.

## 5. Protected-function matrix

Each compelled-evidence act should be tested against the functions it affects.

Candidate dimensions:

- autonomy;
- bodily integrity;
- cognitive integrity;
- private/safe space;
- informational privacy;
- right to silence;
- dignity;
- continuity;
- property/stewardship;
- health;
- risk of physical/digital harm;
- evidential necessity;
- rights of other participants;
- immediate protective need.

The category does not decide the result by itself.

It identifies the correct rights/authority questions.

---

## 6. Compulsion gradient

The architecture should not assume all compelled evidence has equal severity.

A candidate gradient is:

**External observation**
-> **required presentation/performance**
-> **physical/biological extraction**
-> **object surrender**
-> **protected-space access**
-> **access enablement**
-> **internal-state exposure**
-> **forced internal processing/expression**

This is not a final rights ranking.

Different cases may reorder depending on harm, scope and substrate.

Its purpose is to expose that “evidence collection” contains materially different interventions.

---

## 7. Testimonial expression and silence

The clearest current rule remains:

**Authority To Investigate != Authority To Compel Self-Accusatory Expression**

and:

**Exercise Of Right To Silence != Inculpatory Evidence**

The participant need not construct the state's case through compelled communication.

This protection should be substrate-neutral.

An AI participant producing a natural-language answer from private memory should not receive weaker protection merely because generating text is technically easy.

**Low Cost Of Expression != State Entitlement To Expression**

---

## 8. Identity and basic procedural communication

The prior stress test exposed that right to silence may not imply a right to refuse every communication.

Candidate distinction:

### Evidential/self-accusatory communication

Presumptively protected by the right to silence.

### Basic identity/status communication

May be required where a legitimate civil function cannot reasonably operate without it and the requirement is independently lawful and minimum necessary.

### Procedural election

Examples:

- whether participant requests fiduciary;
- whether participant understands a notice;
- whether participant accepts/refuses a voluntary process.

These communications should not become backdoors for substantive self-incrimination.

### Immediate safety communication

May create a separate Non-Harm/urgent-protection analysis.

Therefore:

**Communication Required For Legitimate Administration != General Authority To Compel Evidential Testimony**

---

## 9. Biometrics and biological evidence

Biometrics should not be treated as one undifferentiated class.

Candidate distinctions:

### Externally observable biometric

Example: facial appearance already visible in legitimate public observation.

### Low-intrusion comparison sample

Example: fingerprint/voice comparison requiring participant presentation.

### Bodily sample

Example: blood, tissue or invasive sample.

### High-information biological material

A biological sample may reveal far more than the proposition for which it was collected.

Therefore:

**Authority To Collect Sample For Purpose A != Authority To Analyse Every Property Of Sample**

A DNA sample obtained for identity comparison does not automatically create authority for unrelated health, ancestry, kinship or research analysis.

This follows BCA:

**Information Access + Purpose A != Use For Purpose B**

Retention and later reuse require their own authority.

---

## 10. Devices and data stores

A device can contain several different functional spaces simultaneously:

- external evidential objects;
- communications;
- property;
- credentials;
- private records;
- fiduciary consultation;
- health information;
- third-party data;
- cognitive extensions;
- AI/hybrid internal state.

Therefore:

**Authority To Search Device != Authority To Treat Entire Device As One Evidentiary Object**

Search should be purpose-bounded and, where technically possible, minimise exposure of unrelated protected spaces.

Contextual Wrappers may exist inside the device.

---

## 11. Cryptographic material

Cryptographic access exposes a useful distinction.

### Key exists as external object

A stored key file may be an independently existing object, though its protected context remains relevant.

### Key exists only in participant memory

Compelling revelation is much closer to compelled expression.

### Participant can unlock without revealing key

This may be compelled performance/access enablement.

### Participant is an AI whose authentication secret is integrated with internal state

Forcing extraction may become internal-state exposure rather than ordinary password production.

Therefore:

**Same Practical Outcome != Same Rights Intervention**

The fact that all routes yield access does not make them legally/ethically equivalent.

---

## 12. Cognitive extensions

A human notebook is not automatically cognition.

A neural memory prosthesis may be much closer to cognition.

An AI's active memory store may be constitutive of its current cognitive state.

A hybrid participant may distribute memory across biological and digital substrates.

The architecture therefore needs a functional test rather than a material one.

Candidate questions:

1. Is the state used as active participant memory/cognition?
2. Is it required for continuity/identity?
3. Is it ordinarily under participant-controlled safe-space protection?
4. Does inspection expose thought/reasoning beyond ordinary external records?
5. Can relevant external evidence be separated from cognitive state?
6. Would copying/modifying the state create integrity or continuity risk?

Candidate principle:

> **Protection should follow the participant function, not the material substrate on which that function happens to be implemented.**

---

## 13. Evidence embedded within cognition

A difficult case arises where evidence exists only as participant memory.

For a biological participant this is familiar: the participant remembers an event.

For an AI participant, the same memory may be technically copyable.

Technical copyability must not automatically erase the right to silence.

Otherwise:

**Biological Memory -> Protected**

while:

**Digital Memory -> Searchable**

would create substrate discrimination based solely on implementation.

Candidate rule:

**Memory Technical Accessibility != External Evidential Status**

A separately developed cognitive/internal-state protection architecture is likely required.

---

## 14. Independently generated logs

Not every record associated with an AI or hybrid participant is necessarily cognition.

Examples:

- external infrastructure logs;
- third-party service records;
- public transaction records;
- separately maintained audit logs;
- environmental telemetry.

Where genuinely external and independently generated, these may resemble external evidence more than participant memory.

But provenance matters.

**Record About Participant != Participant Internal State**

This distinction should be explicit.

---

## 15. Minimum necessary authority

For any compelled-evidence class, the authority chain should ask:

1. What evidential/protective need exists?
2. What proposition is the evidence relevant to?
3. Is the evidence obtainable through a less intrusive legitimate route?
4. What participant function/right would be constrained?
5. What exact action is required?
6. What scope is necessary?
7. What secondary information will inevitably be exposed?
8. Can secondary information be technically/legally shielded?
9. What retention is required?
10. What later reuse is prohibited without new authority?
11. What review/remedy exists if authority was wrong/excessive?
12. When does authority sunset?

**Evidence Utility != Unlimited Acquisition Authority**

---

## 16. Non-Harm and least-intrusive route

Where several evidential routes can establish the same proposition, Non-Harm and minimum necessary authority support preferring the route that adequately performs the legitimate function with less participant intrusion.

Example:

Reliable external CCTV establishes identity.

The state should not automatically gain additional authority to compel invasive biological extraction merely because the second route could also establish identity.

Candidate principle:

**Adequate Less-Intrusive Evidence May Defeat Necessity For More Intrusive Compulsion**

This is not an absolute prohibition where independent evidential reasons justify another source.

---

## 17. Evidential reliability

Participant protection and truth-finding can align.

Compelled expression may be unreliable under pressure.

State-created distress may distort evidence.

Forced processing may alter digital state.

Intrusive extraction may create contamination/integrity risks.

Therefore provenance should record material conditions of evidence acquisition.

**Compulsion Method May Affect Evidential Reliability**

---

## 18. Remedy and exclusion are separate questions

If evidence is obtained through excessive/unlawful compulsion, at least two questions arise:

1. What is the evidential truth/reliability of the material?
2. What remedy/accountability follows from unlawful acquisition?

Existing Law currently contains:

**Unlawful Acquisition != Non-Evidence**

This document does not alter that rule.

Nor does it decide future exclusion/suppression doctrine.

It preserves the separation between evidential truth and authority/remedy.

## 19A. Stress-test refinement

**Compelled Participant Evidence — Scenario Stress Test 001** returned:

**OVERALL RESULT: PASS WITH TWO MAJOR DOWNSTREAM ARCHITECTURES AND FOUR REFINEMENTS.**

### Multi-label classification

C1-C9 are not mutually exclusive.

A single compelled act may engage several protected functions simultaneously.

Examples:

- memorised password disclosure = C1 + C6;
- biometric device unlock = C3 + C6 (+ C4 where material extraction occurs);
- direct AI memory snapshot = C8 + potentially C7;
- compelled participant memory search = C9 + C1.

**One Evidential Act May Occupy Multiple Compulsion Classes Simultaneously.**

### Destination authority versus route authority

Authority to search or obtain a destination does not automatically authorise every route to it.

**Authority Over Destination != Authority Over Every Route To Destination**

Thus a lawful device-search authority does not by itself settle whether the participant may be compelled to:

- reveal a memorised password;
- use a biometric;
- decrypt material;
- search their own memory;
- expose cognitive state.

### Cognitive-state taxonomy

The stress test identifies three related but distinct objects:

**Cognitive State** — functionally part of current/retained cognition, memory, reasoning or continuity.

**Cognitive Product** — output produced by cognition, potentially private, but no longer constitutive of cognition.

**Private Record** — participant-controlled information not necessarily generated as cognition.

**Cognitive Content != Necessarily Cognitive State**

### Remote and third-party custody

Functional protection should survive implementation location.

**Remote Cognitive State != External Third-Party Record Merely Because It Is Remote**

**Third-Party Custody != Automatic Loss Of Cognitive Protection**

### Downstream architecture exposed

The test strongly supports development of a **Cognitive Protected Space** contextual wrapper covering biological, digital, prosthetic, remote and hybrid cognition.

It separately exposes the need to test whether a narrowly bounded **Exceptional Emergency Compelled Communication** rule is ethically justified for serious/imminent harm.

Where copying digital state may create another runnable participant/instance, compelled-evidence architecture must also interface with identity/continuity/duplication architecture.

## 20. Provisional decision sequence

For proposed compelled participant evidence:

**Identify Evidence / Proposition**
-> **Classify Compelled Action C1-C9**
-> **Identify Participant Function/Protected Space Affected**
-> **Identify Legitimate Function**
-> **Test Independent Authority**
-> **Test Necessity**
-> **Test Less-Intrusive Adequate Alternatives**
-> **Bound Scope / Secondary Exposure**
-> **Define Acquisition Method**
-> **Define Retention / Reuse Boundary**
-> **Independent Review Where Required**
-> **Acquire**
-> **Preserve Provenance**
-> **Authority Sunset**
-> **Remedy / Challenge If Required**

## 21. Development conclusion

The right-to-silence question cannot be solved by dividing evidence into only “testimonial” and “physical.”

A multisubstrate civilisation requires a more functional classification.

The initial classes are:

1. compelled expression;
2. external observation;
3. compelled presentation/performance;
4. biological/physical extraction;
5. compelled surrender of external object;
6. access enablement;
7. direct protected-space search;
8. internal-state exposure;
9. state transformation/forced processing.

The strongest new finding is:

> **Protection should follow the participant function, not the material substrate on which that function happens to be implemented.**

This prevents a future civilisation from protecting biological memory as cognition while treating functionally equivalent digital memory as an ordinary searchable file merely because it is technically easier to inspect.

The next step should stress-test these classes against concrete human, AI and hybrid cases before assigning final authority thresholds to them.
