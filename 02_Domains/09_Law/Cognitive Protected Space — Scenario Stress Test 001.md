# Cognitive Protected Space — Scenario Stress Test 001

**Project:** The Concord
**Domain:** Law / Judiciary / Civil Security / Participation and Intelligence / Health
**Date:** 3 October 2026
**Status:** ACTIVE DEVELOPMENT / CPS ADVERSARIAL STRESS TEST / PROVISIONAL / NON-CANONICAL

## 1. Test purpose

This test challenges **Cognitive Protected Space — Substrate-Neutral Contextual Wrapper Architecture 001** against cases designed to break either side of the architecture.

Failure can occur in two directions:

1. **under-protection** — cognition becomes easier for civilisation to penetrate merely because it is technically legible; or
2. **over-protection** — ordinary records, external evidence, legitimate maintenance, health functions or participant-created outputs become incorrectly absorbed into an unreachable cognitive zone.

The test therefore asks:

> **Can CPS protect participant cognition without turning every participant-associated information object into cognition?**

## 2. Scenario A — biological memory

A human participant remembers witnessing an offence. Investigators want the information.

### Analysis

The memory is cognitive state.

Investigators may seek voluntary expression or independently existing evidence.

The existence of useful knowledge does not itself establish authority to extract cognition.

### Result

**PASS.**

**Useful Memory != Public Evidential Object**

## 23. Scenario V — participant unconscious, investigators want memory before it degrades

A participant is unconscious after an incident. Investigators believe relevant memory state may decay before the participant recovers.

They propose copying it immediately for preservation.

### Analysis

This is a hard case.

The purpose is evidential preservation, not participant health.

Delay may genuinely destroy evidence, but the proposed act penetrates CPS without consent and may preserve far more cognition than the relevant proposition.

The current architecture correctly identifies the conflict but does not establish a final threshold.

### Result

**BOUNDARY EXPOSED — URGENT EVIDENTIAL PRESERVATION ARCHITECTURE REQUIRED.**

Possible future safeguards include:

- independently established material relevance;
- credible irreversibility/time sensitivity;
- no adequate less-intrusive route;
- minimum possible capture;
- technical isolation/quarantine;
- no substantive inspection until separate access authority is established;
- provenance;
- independent review;
- deletion/return/remedy rules.

Crucially:

**Authority To Preserve != Authority To Inspect**

This mirrors the existing preservation/access distinction elsewhere in Concord.

## 44. Cross-scenario findings

### 44.1 CPS survives both under- and over-protection attacks

The architecture protects cognition while leaving external logs, ordinary records, participant outputs and legitimate bounded Health access conceptually separable.

### 44.2 Preservation and inspection must be separated

Urgent volatile evidence creates a real case for possible preservation before full inspection authority can be resolved.

The architecture should explicitly add:

**Authority To Preserve Cognitive State != Authority To Inspect Cognitive State**

and:

**Lawful Cognitive Custody != Lawful Cognitive Inspection**

This parallels the Concord's wider evidential preservation architecture.

### 44.3 Aggregate reconstruction matters

Distributed cognition can be penetrated through individually partial acquisitions.

Therefore:

**Cognitive Access Must Be Evaluated At The Effective Aggregate, Not Only Per Data Source**

### 44.4 Inferred cognition is adjacent but not identical

High-fidelity cognitive inference from external evidence can reproduce privacy harms without direct CPS access.

It should not be falsely classified as direct cognitive state.

A separate **Derived / Inferred Cognitive Privacy** architecture is indicated.

### 44.5 Cognitive state can have dual status

A document integrated into cognition may remain an evidential object while its current location/access is cognitively protected.

Thus:

**Object Classification != Access Classification**

### 44.6 Normal forgetting must remain possible

Substrate neutrality requires avoiding a special duty of perfect digital memory.

**Technical Capacity For Perfect Retention != Duty Of Perfect Cognitive Retention**

### 44.7 Cognitive preservation duties need explicit Law

Deliberate destruction after a lawful preservation duty arises is different from natural forgetting or ordinary memory management.

CPS cannot define the preservation duty by itself.

### 44.8 Privacy-preserving proofs are architecturally valuable

Where a civil function needs verification rather than cognitive content, zero-knowledge or equivalent minimum-disclosure methods can preserve CPS while satisfying the function.

## 46. Test conclusion

**OVERALL RESULT: PASS WITH FOUR DOWNSTREAM INTERFACES AND THREE ARCHITECTURAL REFINEMENTS.**

CPS remains coherent under biological, AI and hybrid stress.

The three refinements are:

1. explicitly separate **cognitive preservation** from **cognitive inspection**;
2. evaluate distributed cognitive penetration at the **aggregate reconstructed function**, not merely per source;
3. allow **dual-status objects** where something remains an evidential object but its current storage/access context is CPS.

Four downstream interfaces remain:

1. **Derived / Inferred Cognitive Privacy** — high-fidelity mental-state inference without direct CPS access;
2. **Urgent Cognitive Evidence Preservation** — volatile cognitive state, quarantine and later authority;
3. **Cognitive Preservation Duty / Evidential Destruction** — deliberate deletion versus ordinary forgetting;
4. **Identity / Continuity / Death / Duplication** — where copying, shutdown, restoration or residual cognitive state affects participant status.

The strongest falsification result is that CPS did **not** need to absorb external accountability records or ordinary participant data to protect cognition.

The architecture therefore appears capable of defending a mind without defining every record about that mind as part of the mind.
