# Independent Prosecution Function — Referral, Threshold and Adjudication Handoff 001

**Project:** The Concord  
**Domain:** Law / Civil Security / Judiciary  
**Date:** 2 October 2026  
**Status:** ACTIVE DEVELOPMENT / BASIC PROSECUTION FUNCTION / PROVISIONAL / NON-CANONICAL

## 1. Purpose

This document fills the institutional gap between Civil Security investigation and independent Judiciary.

The prosecution function is neither an extension of police investigation nor a preliminary court.

Its bounded function is:

> **Receive the whole evidential state, independently test whether Law's prosecution threshold is satisfied, maintain that assessment as the evidential state changes, and where justified place the legally framed contested case before the independent Judiciary.**

Compact separation:

**Police Establish The Evidential State -> Prosecution Tests Whether Adjudication Is Justified -> Judiciary Determines The Contested Legal Outcome**

Therefore:

**Investigation != Prosecution**  
**Prosecution != Investigation Confirmation**  
**Prosecution != Guilt Determination**  
**Prosecution != Judiciary**

---

## 2. Why a separate prosecution function is required

If police both investigate and decide whether their own case should proceed, investigative commitment can become prosecution authority.

If Judiciary decides whether a case should be constructed and brought before itself, adjudicative independence can be blurred.

The intermediate function therefore has a distinct purpose:

- receive rather than manufacture the investigative case;
- test evidential/legal sufficiency rather than decide guilt;
- preserve inculpatory and exculpatory state;
- formulate the allegation actually supported by the evidence and Law;
- initiate adjudication when the threshold is satisfied;
- terminate or return the matter when it is not;
- continuously reassess its authority when material evidence changes.

**Institutional Separation Supports Functional Separation**

Organisational details remain open, but the functions must remain distinguishable.

---

## 3. Input from Civil Security

The prosecution function should receive a bounded prosecution-referral package sufficient to reconstruct the material evidential state.

Candidate package:

- alleged event/conduct;
- candidate legal classification;
- material inculpatory evidence;
- material exculpatory evidence;
- neutral/unresolved evidence where relevant;
- evidence provenance;
- evidence dependencies;
- reliability/integrity concerns;
- material contradictions;
- alternative materially plausible hypotheses;
- relevant investigative Reality Tree/MRT state where used;
- relevant authority provenance for searches, detention and evidence acquisition;
- known justification/defence evidence;
- unresolved material investigative questions;
- material evidence changes;
- custody/preservation state where relevant.

The package is not a police argument for conviction.

> **Referral Package = Reconstructable Evidential State, Not Advocacy File**

**Prosecution Referral != Inculpatory File Only**

---

## 4. Referral condition

Civil Security does not determine guilt and should not possess an informal veto over sufficiently developed cases through personal belief.

A case should enter independent prosecution assessment when the legally defined referral condition is met.

The referral condition is distinct from the prosecution threshold.

It may be satisfied where, for example:

- investigation has reached a state in which prosecution sufficiency can responsibly be assessed;
- a legally required referral trigger occurs;
- a serious case requires independent threshold review;
- the evidential state is materially contested but sufficiently developed for independent assessment.

The exact referral condition belongs to Law and may vary by case class.

Therefore:

**Referral Condition != Prosecution Threshold**

**Police Referral != Police Finding That Prosecution Threshold Is Met**

This corrects any earlier wording that could imply Civil Security itself makes the final prosecution-threshold determination.

---

## 5. Intake integrity review

On receipt, prosecution first tests whether the evidential package is sufficiently reconstructable to perform its function.

Questions include:

- Is material evidence missing?
- Is contrary evidence represented?
- Are important dependencies visible?
- Is provenance sufficient?
- Are material contradictions exposed?
- Is a known alternative hypothesis omitted?
- Is a required authority record unavailable?
- Has evidence been classified more strongly than its proposition scope supports?

This is not a search for reasons to prosecute.

It is a test of whether the prosecution function can responsibly assess the case.

**Incomplete File != Automatically Insufficient Case**

Where a material omission can legitimately be resolved, prosecution may request completion or clarification.

But:

**Request For Clarification != Authority To Direct Police Toward A Desired Conclusion**

---

## 6. Independent evidential sufficiency assessment

Prosecution applies the legally established prosecution threshold to the whole evidential state.

It must not simply adopt:

- police recommendation;
- investigator confidence;
- MRT aggregate weight;
- automated model confidence;
- number of evidence items;
- seriousness of allegation;
- public pressure;
- institutional preference.

**Police Confidence != Prosecution Threshold**  
**MRT Weight != Prosecution Threshold**  
**Model Confidence != Prosecution Threshold**  
**Serious Allegation != Lower Evidential Requirement**

The assessment asks whether the complete legally relevant evidential state is sufficient to justify independent adjudication.

---

## 7. Possible threshold outcomes

### A. Threshold satisfied

Where the prosecution threshold is independently satisfied:

**Threshold Met -> Prosecution Authority Activates**

Ordinarily the case proceeds, subject only to explicit lawful exceptions.

Prosecution does not need to believe guilt has already been established.

The relevant proposition is:

> **There is sufficient evidential/legal basis for this contested matter to require adjudication.**

### B. Threshold not satisfied but investigation remains live

Where the threshold is not met but a legitimate investigative function remains:

**Threshold Not Met + Material Investigative Gap -> Return/Request Further Legitimate Investigation**

Any request should identify the unresolved evidential question, not prescribe the desired answer.

Example:

**Legitimate:** establish whether the timestamp can be independently verified.

**Illegitimate:** find more evidence that proves A was present.

### C. Threshold not satisfied and no material investigative route remains

**Threshold Not Met + No Continuing Legitimate Investigative Function -> No Prosecution / Closure Or Reclassification**

This does not establish that no event occurred.

### D. Evidential state indicates wrong hypothesis

Where the whole evidential state materially undermines the referred suspect/allegation:

**Failed Suspect Hypothesis -> Do Not Manufacture Prosecutable Case -> Return/Close/Reclassify As Appropriate**

MRT may indicate that the correct next step is hypothesis-space expansion rather than prosecution.

---

## 8. Automaticity after threshold satisfaction

The existing prosecution-threshold architecture establishes a presumption to proceed when the threshold is satisfied.

The prosecution function therefore should not possess unexplained free discretion to suppress a case that satisfies the lawful threshold.

Candidate rule:

> **Threshold Satisfaction -> Ordinary Duty To Proceed, Unless A Separately Lawful Exception Applies**

Any exception must have:

- an explicit legal source;
- a legitimate function;
- bounded scope;
- recorded reasons;
- relevant provenance;
- reviewability;
- functional sunset where applicable.

**Prosecutorial Discretion != Unbounded Permission**

**Institutional Preference != Lawful Exception**

This preserves the user's proposed automaticity while allowing Law to define exceptional cases explicitly rather than hiding them inside personal discretion.

---

## 9. Legal framing of the case

Police establish facts/evidence; prosecution performs the distinct legal task of identifying what allegation the evidence can properly place before Judiciary.

This may require:

- identifying applicable prohibition;
- identifying legally material elements;
- identifying known justification/defence;
- distinguishing complete justification from mitigation;
- narrowing an overbroad police classification;
- separating multiple alleged acts;
- declining unsupported counts;
- recognising that the evidence supports a different legal classification.

**Police Classification != Binding Charge**

**Available Evidence Defines Permissible Legal Framing**

Prosecution must not overcharge merely to create bargaining leverage.

Any future plea/settlement architecture requires separate development and is not authorised by this document.

---

## 10. Relationship to Mirrored Reality Trees

Where Civil Security used Mirrored Reality Trees, the prosecution function receives the relevant evidential structure rather than only its conclusion.

Prosecution may inspect:

- inculpatory structure;
- exculpatory structure;
- unresolved evidence;
- evidence dependencies;
- proposition-scope limits;
- competing/coexisting hypotheses;
- contradiction state;
- hypothesis revisions;
- root-question changes.

But prosecution is not bound by investigator placement or weighting.

**Investigative Tree != Prosecutorial Finding**

If prosecution identifies a material misclassification or omitted plausible hypothesis, the case may require reassessment.

The graduated MRT portable companion remains reasoning infrastructure, not legal authority.

---

## 11. Exculpatory evidence and disclosure integrity

The prosecution function has no legitimate interest in winning by informational asymmetry.

Known materially exculpatory or contradictory evidence remains part of the case state.

**Prosecution != Suppression Of Contrary Evidence**

**Duty To Present A Case != Permission To Distort The Evidential State**

Detailed disclosure rules remain for Law/Judiciary procedure development, but the architecture requires enough disclosure and evidential provenance for the participant and Judiciary to test the case fairly.

Information protections may require bounded disclosure methods rather than unrestricted exposure.

---

## 12. Unlawfully acquired evidence

Under the current Law architecture:

**Unlawful Acquisition != Non-Evidence**

The prosecution function therefore separates:

1. evidential relevance/reliability; and
2. legality/accountability of acquisition.

It must preserve the acquisition-authority provenance necessary for independent review.

**Evidence Useful To Prosecution != Retrospective Authority For Acquisition**

Judiciary remains able to examine the upstream authority exercise and any legally defined consequence/remedy.

---

## 13. Continuing prosecution authority

Prosecution authority is dynamic.

After activation, material changes may include:

- witness recantation;
- newly discovered exculpatory evidence;
- reliability failure;
- forensic correction;
- dependency discovery;
- evidence loss/corruption;
- new alternative hypothesis;
- change in applicable Law;
- judicial ruling affecting the legally usable case.

Therefore:

**Material Evidence Change -> Prosecution Threshold Reassessment**

Possible result:

**Threshold Remains Met -> Continue**

or:

**Threshold No Longer Met -> Prosecution Authority Contracts / Terminates**

Starting a prosecution creates no institutional entitlement to finish it.

**Past Threshold != Permanent Authority**

---

## 14. Handoff to Judiciary

Where prosecution authority remains valid, prosecution provides Judiciary with the legally framed allegation and the evidential/provenance state required by Law and procedure.

The Judiciary then independently determines contested matters.

The handoff must preserve the distinction:

**Prosecution: Is Adjudication Justified?**

**Judiciary: What Is The Legally Valid Finding?**

Judiciary is not asked to ratify a prosecution conclusion.

Prosecution is not permitted to pre-empt Judiciary's finding.

---

## 15. Participant contestability

A participant subjected to prosecution should, subject to legitimate information protections, be able to identify:

- the allegation;
- applicable legal basis;
- material evidential case;
- relevant contrary/exculpatory material as Law requires;
- material provenance necessary to challenge reliability or authority;
- procedural rights;
- routes for challenging prosecution authority;
- material changes in prosecution status.

Detailed procedure remains for later development.

**Ability To Contest != Universal Information Access**

CIBB and protected-information architecture remain applicable.

---

## 16. Independent review of prosecution conduct

The prosecution function itself exercises public authority and therefore falls under the same general Concord principle as policing:

**Public Authority != Self-Validating Authority**

Review may concern:

- threshold application;
- concealment/omission;
- legal framing;
- conflicts of interest;
- unlawful pressure on investigation;
- continuation after threshold collapse;
- misuse of exceptions;
- discriminatory/inconsistent application;
- evidence handling;
- disclosure;
- institutional incentives.

Internal review may assist but does not eliminate independent review where consequential prosecution authority is materially contested.

---

## 17. No prosecution ownership of investigation

Once referral occurs, prosecution may legitimately identify evidential questions that prevent threshold assessment.

It should not become the hidden operational commander of police merely to strengthen its preferred case.

Candidate boundary:

**Prosecution May Identify Evidential Deficit -> Civil Security Determines Lawful Investigative Means**

This preserves:

- investigative neutrality;
- policing authority boundaries;
- prosecution independence;
- auditability.

A prosecutor should not be able to manufacture police authority by requesting an outcome.

---

## 18. No conviction-performance incentive

A prosecution function optimised around conviction rate risks transforming evidential assessment into case selection and adversarial success optimisation.

Candidate system-design principle:

> **Prosecution quality should be measured by lawful, accurate and reviewable threshold application and fair adjudicative handoff, not merely by conviction frequency.**

A lawful acquittal does not by itself prove prosecution failure.

A conviction does not by itself prove prosecution conduct was proper.

**Outcome != Process Validity**

System metrics require later development.

---

## 19. Initial prosecution lifecycle

**Civil Security Investigation**  
-> **Referral Condition Reached**  
-> **Whole Evidential State Transferred**  
-> **Intake Integrity Review**  
-> **Independent Prosecution-Threshold Assessment**

Then:

**Threshold Not Met + Legitimate Investigative Gap**  
-> **Return For Bounded Further Investigation**

or:

**Threshold Not Met + No Legitimate Continuing Route**  
-> **No Prosecution / Closure / Reclassification**

or:

**Threshold Met**  
-> **Prosecution Authority Activates**  
-> **Legal Framing / Disclosure / Case Preparation**  
-> **Continuing Threshold Review**  
-> **Independent Judiciary**

At any point:

**Material Evidence Change -> Reassess**

and:

**Threshold Collapse -> Contract / Terminate Prosecution Authority**

## 21. Architectural position

The previously missing chain is now representable as:

**Incident**  
-> **Civil Security Investigation**  
-> **Mirrored / Whole Evidential State**  
-> **Referral Condition**  
-> **Independent Prosecution Function**  
-> **Legally Established Prosecution Threshold**  
-> **Prosecution Authority Where Satisfied**  
-> **Continuing Evidential Reassessment**  
-> **Independent Judiciary**  
-> **Finding / Remedy / Consequence**

with independent review of police and prosecution authority available alongside the participant-conduct case.

This closes the basic institutional gap between investigation and adjudication without granting guilt-determination authority to either police or prosecution.
