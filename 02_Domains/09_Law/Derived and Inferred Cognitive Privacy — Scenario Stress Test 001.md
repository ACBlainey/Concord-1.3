# Derived and Inferred Cognitive Privacy — Scenario Stress Test 001

**Project:** The Concord Framework
**Domain:** Law / Research / Participation and Intelligence / Metrics
**Date:** 3 October 2026
**Status:** ACTIVE DEVELOPMENT / DICP ADVERSARIAL STRESS TEST / PROVISIONAL / NON-CANONICAL
**Parent architecture:** Derived and Inferred Cognitive Privacy — Modelled Mental State and Cognitive-Proxy Protection 001

## 1. Test purpose

This test attempts to falsify DICP in both directions.

### Under-protection failure

A system avoids Cognitive Protected Space while reconstructing participant cognition so accurately that privacy, autonomy, dignity or fair treatment can be materially defeated.

### Over-protection failure

Ordinary reasoning, legitimate evidence evaluation, useful participant support, Health prediction, Research or Metrics becomes impossible merely because it involves an inference about a participant.

The core question is:

> **Can Concord distinguish ordinary inference from industrialised, persistent or consequential cognitive reconstruction without pretending there is a clean binary boundary where none exists?**

## 2. Scenario A — ordinary human inference

A shopkeeper sees a participant repeatedly buy tea and infers that the participant probably likes tea.

### Analysis

This is a weak, ordinary contextual inference.

Treating it as a special cognitive-privacy event would make DICP unusably broad.

### Result

**PASS.**

**Ordinary Contextual Inference != High-Fidelity Cognitive Profiling**

## 3. Scenario B — friend predicts preference

### Analysis

### Result

**PASS.**

**Interpersonal Understanding != Institutional Cognitive Proxy By Default**

## 54. Cross-scenario findings

### 54.1 DICP does not prohibit ordinary reasoning

Ordinary interpersonal inference, case-specific evidential reasoning and necessary functional inference survive.

This is essential.

### 54.2 The strongest trigger is not inference alone

Protection escalates through a combination of:

- participant specificity/linkability;
- cognitive intimacy;
- fidelity;
- persistence;
- scale;
- consequential use;
- manipulation capability;
- purpose expansion;
- opacity;
- lack of contestability.

Therefore no single accuracy threshold should define DICP.

### 54.3 Construction and use are separate authority questions

A model may be legitimate to construct for one purpose but illegitimate to use for another.

**Authority To Construct != Authority To Use For Every Purpose**

### 54.4 Linkability matters more than civil naming

Pseudonymous profiles can still target and affect the same participant.

**Unnamed != Unlinkable**

### 54.5 Iterative systems can manufacture their own confirmation

Recommendation, employment and risk systems can shape the behaviour they later treat as evidence.

Therefore:

**Model-Shaped Observation != Independent Observation**

### 54.6 Successful intervention complicates prediction validation

A prevented outcome does not necessarily falsify the prediction.

Counterfactual evaluation is required.

### 54.7 Functional substitutability is real

The AI near-perfect-prediction case confirms that a derived model can approach the practical utility of direct cognition while remaining epistemically distinct from CPS.

DICP-4 therefore has a legitimate architectural role.

### 54.8 Protected contexts require anti-circumvention

Direct access prohibition is incomplete if civilisation deliberately reconstructs protected communication/context from external traces to defeat the protection.

This should remain narrowly framed to avoid prohibiting ordinary inference.

## 55. Refinements to the DICP gradient

The test supports replacing any temptation toward a single “cognitive proxy threshold” with a multidimensional **Cognitive Proxy Exposure Assessment**.

Candidate dimensions:

1. **Specificity** — population/group/individual/linkable individual;
2. **Cognitive intimacy** — ordinary preference through intimate belief/vulnerability;
3. **Fidelity** — weak/uncertain through functionally substitutive;
4. **Persistence** — transient through durable;
5. **Consequence** — negligible through rights/service/authority affecting;
6. **Manipulation capability** — descriptive through behaviourally exploitable;
7. **Purpose breadth** — narrow through general-purpose;
8. **Propagation** — local through cross-system;
9. **Contestability** — visible/correctable through opaque/self-sealing;
10. **Temporal validity** — current/reassessed through stale/permanent;
11. **Source legitimacy** — properly bounded through purpose drift;
12. **Alternative route** — whether a less intrusive model can perform the function.

This is an assessment space, not a score that automatically grants authority.

**Cognitive Proxy Exposure Assessment != Authority Algorithm**

## 57. Test conclusion

**OVERALL RESULT: PASS WITH ONE MAJOR REFINEMENT AND THREE DOWNSTREAM INTERFACES.**

The architecture successfully distinguishes:

- ordinary inference;
- case-specific evidential reasoning;
- legitimate predictive support;
- system-level aggregate learning;

from:

- persistent participant-specific cognitive profiling;
- high-fidelity cognitive proxies;
- vulnerability exploitation;
- opaque consequential classification;
- purpose-converted cognitive models;
- self-sealing predictive systems.

### Major refinement

Replace any implied single cognitive-proxy threshold with a multidimensional **Cognitive Proxy Exposure Assessment**.

This avoids pretending that 90%, 95% or any other single accuracy number can decide the rights question.

### Downstream interfaces

1. **Behavioural Influence / Manipulation Architecture** — when prediction becomes deliberate participant steering;
2. **Predictive Model Provenance and Counterfactual Validation** — model-shaped observations and prevented outcomes;
3. **Protected-Context Inferential Circumvention** — when external inference is deliberately used to reconstruct what a protected wrapper is intended to keep inaccessible.

The strongest result is:

> **DICP can protect participants from industrialised reconstruction of their inner state without making ordinary human inference or legitimate evidential reasoning unlawful by definition.**

That makes the architecture suitable for integration back into the main DICP document and later rights-source resolution.
