## Section-by-section method

1. Select one chapter range and retrieve the matching V2 and V2.1 text.
2. Compare both against earlier V1/V1.2 governance architecture and relevant recovery material and cross-domain sources. Portable Modules are independent, subordinate external artefacts and must not be used as governing architecture or cited inside operational systems.
3. Identify each substantive addition, omission, difference or conflict. Preserve the complete meaning of the architecture rather than compressing it into summaries.
4. Integrate the material directly into a single V2.2 working section in `Work/`, placing rules in their relevant numbered subsections. Resolve textual conflicts using the Concord architecture and record genuinely outstanding design questions in place.
5. Re-read the saved working section from GitHub and check the actual content against all sources considered. A successful write or a separate integration draft does not establish that content was incorporated.
6. Continue with the next section only after its source material has been accounted for.

Do not create parallel integration drafts, separate issue registers or multiple versions of the same section unless specifically requested. Keep working notes within the section file where practical.

## Mandatory authority interpretation for future reviews

**Standing functional mandate clarification:** The absence-of-authority presumption does not negate a domain's expressly assigned functions. Those functions provide a bounded standing mandate for routine work within stated conditions; no new triadic vote is needed for each routine act. Holding another domain's records or transmitting its decisions does not confer the authority described in them. Reviewers must preserve existing operational functions while requiring an explicit additional mandate for any expansion beyond their scope. This rule applies across all Concord domains; see [`02_Domains/README.md`](../../README.md).


Start with Chapter 1's **Default Absence of Authority — Explicit-Method Rule**. No participant possesses institutional authority by default. Only explicitly described, valid contextual mechanisms can create or exercise bounded authority; missing methods mean no authority exists, not an implicit power. Personal rights-based authority over the self, including lawful self-defence, is separate. Review actual documented mechanisms and real bypass risks; do not repeatedly invent hypothetical authority-granting pathways absent from Concord's design.
