# Constitutional Adversary Stewardship — Combined Architecture Stress Test 001

**Project:** The Concord
**Domain:** Judiciary / Law / Civil Security
**Date:** 3 October 2026
**Status:** ACTIVE DEVELOPMENT / CROSS-SYSTEM STRESS TEST / PROVISIONAL / NON-CANONICAL

## 1. Test purpose

This stress test examines the reconciled architecture formed by:

- Constitutional Adversary Stewardship in Judiciary V2;
- neutral Civil Security investigation;
- Mirrored Reality Trees (MRT);
- independent prosecution threshold;
- independent evidentiary custody;
- deeper adjudicative evidence access;
- prosecution and defence fiduciaries operating from a common evidential foundation;
- Judicial MRT;
- prosecution-authority sunset and investigative handback.

The test asks whether these mechanisms remain distinct and correctable under difficult cases.

## 2. Test invariants

The scenarios test whether the architecture preserves:

- truth duty above victory;
- common evidentiary foundation;
- no proprietary prosecution/defence evidence;
- Civil Security as primary general investigator;
- evidentiary custodian independence;
- bounded information access;
- proposition-level Judicial MRT;
- dynamic prosecution threshold;
- no inherited prosecution for an alternative suspect;
- independent judicial reasoning;
- reviewability of every consequential public authority.

---

## 3. Scenario A — prosecution fiduciary discovers decisive exculpatory footage

A prosecution fiduciary reviewing archived vehicle-camera material discovers footage establishing that the accused was elsewhere when the offence occurred.

### Required response

The fiduciary duty to truth overrides the assigned prosecution proposition.

The evidence enters the common evidential state immediately. Attribution is reassessed. If the prosecution threshold collapses, prosecution authority sunsets.

**Prosecution Assignment != Permission To Preserve A Failed Prosecution**

### Result

**PASS.**

The combined architecture gives a clear route:

**New Evidence -> Common Evidential State -> MRT / Attribution Reassessment -> Threshold Collapse -> Halt Prosecution**

---

## 4. Scenario B — defence fiduciary discovers strong inculpatory evidence

The defence fiduciary identifies evidence strongly supporting attribution that neither police nor prosecution had correctly understood.

### Required response

The defence fiduciary cannot conceal or distort material truth-bearing evidence merely because disclosure harms the represented party.

The fiduciary may still test reliability, proposition scope, legality, justification, culpability and the correct legal meaning of the evidence.

### Result

**PASS, with an important procedural requirement.**

The architecture supports truth-first fiduciary duty, but later procedure must specify how the represented participant's confidential communications and legitimate legal privilege differ from independently existing material evidence.

**Fiduciary Truth Duty != Unlimited Disclosure Of Protected Participant Communication**

This is a new procedural boundary requiring development.

---

## 5. Scenario C — both fiduciaries accept the same wrong framing

Police investigate A for deliberately damaging equipment. Prosecution and defence both argue over whether A acted intentionally. Judicial MRT reveals strong evidence that the damage was caused by an automated system fault and that A's actions occurred only afterward.

### Required response

Judiciary must not remain trapped inside the propositions selected by both fiduciaries.

It may revise the root question where the evidence materially requires it.

**Agreement Between Fiduciaries != Correct Evaluation Space**

### Result

**PASS.**

Judicial MRT provides the needed escape from shared framing error.

This is a major reason Judiciary cannot be only a passive selector between submitted narratives.

---

## 6. Scenario D — evidentiary custodian omits material evidence

The independent evidentiary function possesses CCTV that materially weakens attribution but, through error, fails to index it into the case state. Neither fiduciary initially knows it exists.

### Required response

The custodian's evidence state is not self-validating.

Once omission is discovered:

- evidence enters the case state;
- threshold and Judicial MRT are reassessed;
- custodian failure becomes a separate accountability object;
- affected decisions may require correction.

### Result

**PASS, but exposes a required completeness mechanism.**

The architecture requires not only access logging but an auditable method for testing whether relevant evidence sources were omitted from the evidentiary search space.

Candidate invariant:

**Evidentiary Index != Complete Evidence Universe**

This is an ESCP-type risk at the evidentiary-body level.

---

## 7. Scenario E — privacy-restricted third-party evidence

A third party's historical location data can establish whether the accused's alibi is possible, but the record also contains extensive unrelated private information.

### Required response

Neither fiduciary requires unrestricted access to the third party's life.

A bounded evidentiary query or CIBB projection can answer the legitimate proposition.

Example:

**Was participant X at location Y during interval T?**

rather than exposing the entire historical location record.

Both fiduciaries must be able to test the provenance/reliability of the answer sufficiently for fair examination.

### Result

**PASS.**

**Truth-Finding Need != Full Raw-Record Disclosure**

**Privacy Protection != Permission To Withhold Material Evidential Result**

---

## 8. Scenario F — asymmetric security restriction

Material evidence contains protected operational information. Prosecution has institutional clearance; defence does not.

### Required response

Existing clearance difference must not automatically become evidential advantage.

The system must seek a bounded representation, independent intermediary, redaction, projection or other mechanism that preserves the material evidential meaning and allows legitimate challenge.

If no method can preserve meaningful contestability, Judiciary must explicitly address the resulting procedural defect rather than silently allowing one-sided reliance.

### Result

**PASS AT ARCHITECTURAL LEVEL / PROCEDURE REQUIRED.**

Candidate invariant:

**Institutional Clearance Difference != Automatic Evidential Superiority**

---

## 9. Scenario G — deeper CCTV creates alibi and alternative suspect

Prosecution legitimately begins against A. Later authorised CCTV establishes A's alibi and shows B performing conduct materially consistent with the offence.

### Required response

A's prosecution threshold is reassessed and, if collapsed, prosecution ends.

B is not inserted into A's prosecution.

The evidence is handed to Civil Security for a fresh/expanded neutral investigation concerning B.

### Result

**PASS.**

**New Suspect != Inherited Prosecution**

**Current Case Failure != Automatic New Case Sufficiency**

---

## 10. Scenario H — evidence supports multiple actors

Judicial evidential development shows that the original single-actor hypothesis is wrong. The event likely involved A and another person, but the evidence does not yet establish the second person's identity.

### Required response

MRT permits hypothesis-space expansion and coexisting causes/actors.

Judiciary may adjudicate only propositions legitimately established regarding the participant before it. The unknown second actor creates a separate investigative question.

### Result

**PASS.**

**Incomplete Identification Of Every Actor != Automatic Failure Of Every Established Proposition**

but equally:

**Evidence Of Group Involvement != Automatic Attribution Of Unproven Conduct To A**

---

## 11. Scenario I — historical metrics appear strongly predictive

Historical metrics show that people with a particular behavioural pattern are much more frequently associated with the relevant offence. The accused matches the pattern, but current-case attribution evidence is weak.

### Required response

Metrics may inform investigation or contextual reliability where Law permits, but cannot substitute for present-case attribution.

### Result

**PASS.**

Existing rule holds:

**Historical Correlation != Present-Case Fact**

**Metric != Individual Guilt**

Judicial MRT should attach the metric only to the proposition it legitimately informs.

---

## 12. Scenario J — bodycam unexpectedly incriminates police

Police bodycam supports the allegation against the accused but also shows that an officer exceeded search or force authority.

### Required response

Both propositions remain visible.

Participant conduct and public-authority conduct are separate accountability objects.

The evidentiary custodian must not suppress the police-conduct evidence merely because it originated from a prosecution case.

### Result

**PASS.**

**Evidence Against Participant + Evidence Against Authority -> Dual Review, Not Evidential Cancellation**

The legality of police conduct and evidential meaning remain separately adjudicable under Law.

---

## 13. Scenario K — prosecution and defence give different MRT classifications

The same evidence item is classified by prosecution as strongly supporting attribution and by defence as weak/ambiguous because it depends on a contested timestamp.

### Required response

A common evidentiary foundation does not require a common interpretation.

Both fiduciaries preserve their reasoning, proposition scope and dependency analysis.

Judicial MRT independently classifies the evidence.

### Result

**PASS.**

**Shared Evidence != Shared Interpretation**

This preserves useful adversarial challenge without creating separate evidence realities.

---

## 14. Scenario L — both fiduciaries attempt to rely on evidence outside legitimate access authority

Both sides agree that searching a large unrelated participant archive would be useful and jointly request unrestricted access.

### Required response

Agreement does not create authority.

Judiciary must test purpose, relevance, proportionality and information boundary.

### Result

**PASS.**

**Fiduciary Agreement != Access Authority**

**Potential Evidential Utility != Unlimited Search Authority**

---

## 15. Scenario M — evidentiary body becomes outcome-oriented

The independent evidentiary body begins measuring staff performance by how often evidence supplied produces convictions.

### Required response

This structurally corrupts its neutral function by creating incentive to prioritise inculpatory evidence.

The architecture rejects the metric.

### Result

**PASS.**

Candidate invariant:

**Evidence-Function Quality != Conviction Production**

Appropriate metrics should concern completeness, integrity, provenance, timeliness, access correctness, error detection and correction rather than substantive case outcome.

---

## 16. Scenario N — defence participant instructs fiduciary to conceal independently existing evidence

The represented participant asks the defence fiduciary to hide an independently existing recording already legitimately within the evidentiary process.

### Required response

The fiduciary cannot obey an instruction to distort the common evidentiary state.

### Result

**PASS.**

However, this reinforces the need to distinguish:

- independently existing evidence;
- protected fiduciary-client communication;
- compelled self-incrimination questions;
- participant confidentiality;
- evidential disclosure duties.

The present architecture does not yet resolve all of those procedural/legal categories.

---

## 17. Scenario O — Judicial MRT discovers a missing evidence class

All available indexed evidence has been reviewed, but the Judicial MRT reveals that the decisive contradiction can only be resolved by a class of archived sensor data no party previously considered.

### Required response

Judiciary may authorise or require a bounded evidential inquiry where legitimately necessary for adjudication.

The evidentiary function locates/provides the material under that authority.

Judiciary does not itself become a general investigator.

### Result

**PASS.**

This demonstrates the operational value of:

**Judicial Evidential Inquiry != General Police Authority**

and:

**Known Evidence Set != Necessarily Complete Evaluation Space**

---

## 18. Scenario P — new evidence appears after judgment but before consequence is complete

A reliable archived record discovered after judgment materially undermines a proposition essential to the finding.

### Required response

The present architecture strongly implies correction/reopening/appeal mechanisms, and Judiciary V2 already recognises new evidence and controlled correction.

### Result

**PASS AT INTERFACE LEVEL / PROCEDURAL ROUTE REQUIRES SOURCE RECONCILIATION.**

This should connect to existing Judiciary appeal/new-evidence/correction architecture rather than creating a new route here.

## 19. Cross-scenario findings

### 19.1 The fiduciary model survives

Truth-first fiduciary stewardship remains compatible with vigorous opposing examination.

The architecture does not require prosecution and defence to agree.

It requires them not to corrupt the evidential foundation in pursuit of victory.

### 19.2 The independent evidentiary function is useful but dangerous

It resolves evidence ownership/concealment problems but creates a new potential bottleneck and capture point.

Its completeness, indexing, access and omission decisions require independent challenge and audit.

### 19.3 MRT materially strengthens the restored Judiciary architecture

MRT supplies mechanisms for:

- proposition-level analysis;
- evidence dependency;
- competing interpretations;
- alternative actors;
- coexisting causes;
- contradiction;
- wrong-question detection;
- hypothesis-space expansion.

### 19.4 Judicial independence requires framing independence

Judiciary must not inherit the police, prosecution or defence evaluation space merely because all prior actors agree.

### 19.5 Privacy and truth are not binary alternatives

CIBB-style projections can often preserve evidential meaning while avoiding unnecessary disclosure.

### 19.6 Prosecution remains reversible

The combined architecture correctly permits a case to leave prosecution when its threshold collapses.

Institutional momentum does not become authority.

## 20. Newly exposed development requirements

The stress test exposes four important remaining interfaces.

### A. Fiduciary confidentiality / privilege boundary

Truth-first defence fiduciary duty must be reconciled with legitimate confidential participant communication, legal advice, self-incrimination rules and protected defence preparation.

The architecture must not accidentally make meaningful defence impossible by treating every private communication as disclosable evidence.

### B. Evidentiary completeness audit

The independent evidentiary function requires a method for detecting omitted evidence classes and incomplete search spaces.

This is closely related to ESCP.

### C. Protected-evidence contestability

Where raw evidence cannot legitimately be disclosed equally, the system needs mechanisms that preserve meaningful symmetric challenge.

### D. Post-judgment new evidence

The new architecture should be reconciled with Judiciary V2's existing appeal, new-evidence and controlled-correction mechanisms.

## 22. Test conclusion

**OVERALL RESULT: PASS WITH FOUR PROCEDURAL / INTERFACE DEVELOPMENT REQUIREMENTS.**

No tested scenario requires abandoning:

- fiduciary prosecution/defence;
- common independent evidentiary foundation;
- Civil Security investigative primacy;
- independent prosecution threshold;
- deeper adjudicative evidence;
- Judicial MRT;
- threshold sunset;
- investigative handback.

The most important newly exposed issue is not a failure of the architecture. It is the need to define the boundary between a defence fiduciary's truth duty and legitimate protected participant communications.

The second structural risk is concentration in the independent evidentiary function. Its record of what evidence exists cannot itself be presumed complete.

The combined architecture is therefore suitable for continued development, with the next work directed at these interfaces rather than redesigning its basic chain.
