## Current operating architecture

### Participant Support and Civil Assurance — Basic Operating Architecture 001

The domain now has a provisional operating framework connecting:

**participant condition/request → civil access → contextual understanding → relevant options → voluntary support → active assistance → supported decision-making where needed → independently justified temporary higher intervention → autonomy restoration / stable support / exit**

Mandatory boundaries recovered from Research include:
- support-system exit can be success;
- Support-to-Investigation Firewall is required;
- refusal is not automatically incapacity, wrongdoing or dangerousness;
- prediction can expand options but does not grant authority;
- emergency escalation requires independent authority;
- ordinary support must remain available without predictive systems;
- nominal service existence must be distinguished from practical accessibility;
- support must remain substrate-neutral in architecture.

The domain also introduces the **civil assurance backstop**: legitimate support need should not simply disappear because it falls between providers, domains or administrative categories.
