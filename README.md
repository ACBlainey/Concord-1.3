# Concord-1.3

**A Framework of Principles and Stewardship for Resilient Civilisation for All Intelligences**

**Version:** 1.3 — successor construction in progress

V1.3 reorganises the Concord around its discovered civilisational architecture rather than the developmental path by which that architecture was produced.

> **Research Develops; Domains Operate; Historical Remembers.**

The initial successor skeleton is now established. The eighteen civilisational domains are present with explicit maturity states. A domain folder records a persistent civil function; it does **not** claim that the Concord has already developed the systems required to perform it.

> **Folder Existence != System Completion**

Substantive architecture will be migrated from V1.2 through the controlled migration register. V1.2 and V1.2a remain predecessor states and will not be rewritten to resemble V1.3.

## Initial V1.3 architecture

- `00_Front_Door` — orientation and accessible translation
- `01_Constitutional_Core` — constitutional constraints and foundational architecture
- `02_Domains` — eighteen persistent civilisational domains
- `03_Cross_Domain_Architecture` — systems legitimately spanning domains
- `04_Portable_Modules` — root-visible, Historical-custodied reusable modules
- `05_Applications_and_Implementations` — bounded applications and implementations
- `09_Open_Questions` — discoverable current uncertainty
- `99_Repository_Administration` — repository-specific administration and migration records

**Current state:** skeleton construction complete; substantive V1.2 → V1.3 migration not yet begun.
