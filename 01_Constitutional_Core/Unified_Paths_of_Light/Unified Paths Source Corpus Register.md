## Purpose

This register provides one provenance and navigation layer for the source corpora used by Unified Paths. It records primary derivation material, withheld validation material, source/translation controls, actual closure boundary, key provenance records and frozen outputs.

**Register ≠ New Evidence.** Unknown details remain unknown rather than being reconstructed from memory.
