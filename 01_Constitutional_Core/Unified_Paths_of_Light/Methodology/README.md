# Unified Paths of Light — Methodology

## Purpose

This folder contains the reusable methodology governing anchor-reversal comparative ethics experiments following the original Psalm study and E3 Qur'an-first replication.

It exists because E3 demonstrated that an exact methodological replication cannot mean imposing the same documentary unit on traditions whose source architectures differ radically.

The invariant must be the **analytical transformation and evidential controls**, not the physical form, number or length of source documents.

## Core methodological principle

> **Standardise the criteria for ethical extraction, not the size or literary form of the source unit.**

Future anchor experiments should therefore preserve:

- a predefined and documented search space;
- source-form-appropriate Ethical Source Units;
- extraction before cross-traditional comparison;
- preservation of source occurrences before compression;
- independent normalisation and consolidation;
- explicit freeze points;
- source-quality controls;
- explicit closure criteria;
- post-freeze external validation;
- preservation and classification of disagreements;
- separation between anchor-derived findings and later comparison with the Concord.

## Living methodology

This folder is intentionally a methodology workspace rather than a single final paper.

Large, distributed or internally heterogeneous traditions are expected to expose further methodological problems. New methodological notes should be added here as those problems are discovered, while preserving the version of the protocol under which each experiment was conducted.

Method changes must not be retroactively hidden. Where a later experiment reveals a material weakness, the change should be documented and earlier experiments re-audited only where the weakness could affect their conclusions.
