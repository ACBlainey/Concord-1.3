# Ten Commandments Comparative Project
## Concord Ethical Kernel, E3 Attractors and the Decalogue

This subproject compares three independently significant ethical structures:

1. the biblical Decalogue / Ten Commandments;
2. the Concord Ethical Kernel (Blainey's Laws);
3. the frozen ten-attractor layer independently derived in E3.

The numerical coincidence of “ten” in E3 is not treated as evidence. The purpose is structural comparison: determine which ethical functions genuinely correspond, which appear only as downstream implications, and which remain clearly different.

## Methodological rule

The comparison must not rewrite any of the three systems to manufacture agreement.

The Decalogue is analysed first in its own textual and covenantal context. Because Jewish, Catholic/Lutheran and Reformed/Orthodox traditions enumerate the “Ten Words” differently, the project uses the underlying command units of Exodus 20:1–17 and Deuteronomy 5:6–21 rather than treating one later numbering convention as uniquely canonical.

The project distinguishes:
- **direct functional correspondence**;
- **strong derived correspondence**;
- **partial or contextual correspondence**;
- **no clear correspondence**.

Theological commands are retained rather than discarded merely because the Concord is substrate-neutral.
