## First major finding

The subtle E3 extensions are not random verbosity.

Several Decalogue commands map **more precisely to the expanded E3 attractor formulation than to a single minimal Blainey's Law**:

- misuse of sacred authority → A2 + A6;
- Sabbath → A5 + A8 + A9;
- honour parents → A5 + A6 + A7;
- adultery → A4 + A6;
- false witness → A2 + A3;
- coveting → A8 + A9 + A10.

This is consistent with the hypothesis that the E3 attractor layer sits between the minimal kernel and concrete behavioural rules.

## Compression interpretation

A plausible architecture is therefore:

**minimal ethical root**  
→ **higher-order functional attractor**  
→ **specific behavioural rule**  
→ **institutional implementation.**

On this interpretation Blainey's Laws are cleaner because they are more compressed, while E3 retains enough intermediate structure to map more directly onto historically specific rules.

This remains a hypothesis until the reverse comparison is completed.
